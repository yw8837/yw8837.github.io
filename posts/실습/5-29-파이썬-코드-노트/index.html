파이썬 첫 실습 — 기초 자료형·조건문·리스트를 강사님 노트북 코드 그대로 정리하고, 한 줄씩 풀어 설명했습니다. 각 개념마다 ① 한 줄 설명 → ② 코드 → ③ 출력 → ④ 한 줄씩 뜯어보기 → ⑤ 팁 순서예요. 직접 쳐보면서 익히세요! 🚀

Part 1. 기초 자료형#

1. 출력 — print()#

print()는 괄호 안의 값을 화면에 보여주는 가장 기본 함수입니다.

print("나의 꿈은 파이썬 정복!")

# 콤마로 여러 값을 공백 구분하여 한 줄 출력
print(3, "Hello!")
print("이름:", "Alice", "나이:", 20)

# print 여러 번 → 여러 줄 출력
print("비행기에 타신 승객 여러분")
print("행복한 여행 되십시오")
print("기내식은 바밤바")

출력:

나의 꿈은 파이썬 정복!
3 Hello!
이름: Alice 나이: 20
비행기에 타신 승객 여러분
행복한 여행 되십시오
기내식은 바밤바

🔍 한 줄씩

  • print("...") → 따옴표 안 글자를 그대로 출력
  • 콤마(,)로 여러 개를 넘기면 자동으로 한 칸 띄어서 이어 줍니다
  • print를 여러 번 쓰면 줄이 바뀌며 출력됩니다
# 계산식도 print 안에서 바로 계산됨
print("나이:", 20, "학년:", 2)
print(100, "+", 200, "=", 100 + 200)

출력:

나이: 20 학년: 2
100 + 200 = 300

💡 "+"(따옴표 안)는 글자 +, 100 + 200(따옴표 밖)은 진짜 덧셈입니다. 그래서 결과가 300으로 나와요.

2. 기본 자료형 — 데이터의 종류#

컴퓨터는 숫자와 글자를 다르게 취급합니다. 파이썬의 기본 자료형을 봅니다.

# 숫자형
print(type(3))       # <class 'int'>   정수
print(type(3.14))    # <class 'float'> 실수

# 문자열
print(type("Hello")) # <class 'str'>
print('작은따옴표도 OK')
print("큰따옴표도 OK")

# 리스트
print([])                    # 빈 리스트
print(['a', 'b', 'c'])       # 문자열 리스트
print(['a', 2, 3.14, True])  # 여러 자료형 혼합 가능
print(type([1, 2, 3]))       # <class 'list'>

# 논리형
print(type(True))            # <class 'bool'>

🔍 자료형 5가지

  • int 정수 (3, -10) / float 실수 (3.14)
  • str 문자열 — 따옴표로 감싼 글자. 작은/큰따옴표 둘 다 OK
  • list 리스트 — []에 여러 값을 순서대로. 다른 자료형 섞어도 됨
  • bool 논리형 — True/False 두 가지

💡 type(값)은 “이게 무슨 자료형이지?“를 알려주는 도구입니다. “왜 안 되지?” 할 때 첫 번째로 찍어보는 디버깅 도구예요.

3. 변수 (Variable) — 값에 이름표 붙이기#

변수는 데이터를 담는 이름 붙은 그릇입니다. 변수명 = 값 형태로 만듭니다.

num   = 10
name  = "Michael"
grade = ['A+', 'B+', 'A0']

print(num)    # 10
print(name)   # Michael
print(grade)  # ['A+', 'B+', 'A0']

# 스네이크 표기법 (권장)
prod_name = "milk"
prod_date = "2024-10-08"
print(prod_name, prod_date)

🔍 이름 규칙

  • 숫자로 시작 불가 (1num ❌)
  • 공백·연산자 불가 (my name ❌ → my_name ✅)
  • 예약어(if, for 등) 사용 불가
  • 단어 사이를 _로 잇는 스네이크 표기법(prod_name)이 파이썬 공식 스타일
# 변수는 언제든 새 값으로 덮어쓸 수 있음
score = 50
print("처음 점수:", score)   # 50

score = 100          # 덮어쓰기
print("바뀐 점수:", score)   # 100

💡 =는 “같다"가 아니라 “오른쪽 값을 왼쪽 이름에 넣어라” 는 뜻입니다.

4. 자료형의 연산#

연산자 의미 예시 결과
+ - * / 사칙연산 3 + 5 8
// 몫 13 // 5 2
% 나머지 13 % 5 3
** 제곱 2 ** 4 16
+ (문자열) 이어붙이기 "안녕" + "하세요" "안녕하세요"
* (문자열) 반복 "안녕" * 3 "안녕안녕안녕" 
# 숫자형 사칙연산
print(3 + 5)   # 8
print(3 / 5)   # 0.6  ← 나눗셈은 항상 실수(float) 반환

# 특수연산
print(13 // 5) # 2  (몫)
print(13 % 5)  # 3  (나머지)
print(2 ** 4)  # 16 (제곱)

# 문자열 연산
print("안녕" + "하세요")  # 안녕하세요
print("안녕" * 3)         # 안녕안녕안녕

💡 나눗셈 /는 정수끼리 나눠도 결과가 실수예요 (6 / 2 → 3.0). 정수 몫만 원하면 //를 씁니다.

# 숫자를 문자열과 이어붙이려면 str() 변환 필요
age_num = 20
# print("나이: " + age_num)   # ← TypeError! (문자 + 숫자 불가)
print("나이: " + str(age_num))  # 나이: 20

⚠️ 문자열 + 숫자는 에러(TypeError) 입니다. 숫자를 str()로 바꿔야 이어붙일 수 있어요.

5. 인덱싱 & 슬라이싱 — 원하는 부분 꺼내기#

문자열·리스트는 순서가 있어서 위치 번호로 꺼낼 수 있습니다. 번호는 0부터 시작해요.

"Ready"  →  R  e  a  d  y
인덱스   →  0  1  2  3  4   (앞에서)
           -5 -4 -3 -2 -1   (뒤에서, 음수)

word    = "Ready"
numbers = [2, 4, 6, 8, 10]

# 인덱싱 — 한 개 꺼내기
print(word[0])      # R   첫 번째
print(word[-1])     # y   뒤에서 첫 번째
print(numbers[2])   # 6
print(numbers[-1])  # 10

# 슬라이싱 — 범위 꺼내기 [시작:끝]  (끝은 미포함!)
beta = [2, 4, 6, 8, 10, 12, 14]
print(beta[2:5])    # [6, 8, 10]      인덱스 2,3,4
print(beta[:3])     # [2, 4, 6]       처음부터
print(beta[4:])     # [10, 12, 14]    끝까지
print(beta[:])      # 전체 복사

⚠️ 슬라이싱의 끝 번호는 포함되지 않습니다. beta[2:5]는 인덱스 2,3,4까지(5는 제외).

# 중첩 리스트 — 리스트 안의 리스트
student_info = ["홍길동", 20, "컴퓨터공학과", [90, 85, 100, 78, 92]]

print(student_info[0])       # 홍길동
print(student_info[3])       # [90, 85, 100, 78, 92]  (내부 리스트)
print(student_info[3][0])    # 90   ← [3]으로 리스트 꺼내고 [0]으로 첫 점수

💡 student_info[3][0] → 먼저 [3]으로 점수 리스트를 꺼내고, 거기서 다시 [0]으로 첫 점수를 꺼냅니다. 두 번 인덱싱.

Part 2. 조건문#

조건문은 “만약 ~라면 A, 아니면 B” 라는 갈림길입니다.

1. 입력 — input()#

# input() 반환값은 항상 문자열(str)!
var1 = "100"
var2 = "300"

print("문자열 더하기:", var1 + var2)            # 100300 (이어붙임!)
print("숫자로 더하기:", int(var1) + int(var2))  # 400    (덧셈)

⚠️ input()으로 받은 값은 무조건 문자열입니다. "100" + "300"은 "100300"(글자 이어붙이기)이 되니, 계산하려면 int()로 바꿔야 해요.

형 변환 (Type Casting)#

a = "345"
b = int("345")
print(a, type(a))    # 345 <class 'str'>
print(b, type(b))    # 345 <class 'int'>

print(float("3.14"))   # 3.14   문자열 → 실수
print(str(1000))       # "1000" 숫자 → 문자열
print(list("1008"))    # ['1', '0', '0', '8']  문자열 → 리스트
함수 변환 예시
int() → 정수 int("345") → 345
float() → 실수 float("3.14") → 3.14
str() → 문자열 str(1000) → "1000"
list() → 리스트 list("ab") → ['a','b']

2. 비교·논리 연산자#

조건을 표현하는 연산자입니다. 결과는 항상 True/False.

연산자 의미 예시 → 결과
== 같다 3 == 3 → True
!= 다르다 3 != 5 → True
< > <= >= 크기 비교 3 < 5 → True
and 둘 다 True True and False → False
or 하나라도 True True or False → True
not 반전 not True → False 
# 비교 연산자
print(3 < 5)    # True
print(7 == 5)   # False
print(5 != 10)  # True

# and: 모두 True여야 True
print(3==3 and 4<=5 and 6>2)   # True
print(3==3 and 4>5)            # False

# or: 하나라도 True면 True
print(3==4 or 4<=5 or 6<2)    # True

# not: 논리값 반전
print(not 3==4)   # True  (False를 뒤집음)

⚠️ =(하나)는 대입, ==(둘)은 비교입니다. 가장 많이 하는 실수예요.

# 실생활 조건을 논리 연산자로
age        = 25
height     = 170
has_ticket = True

can_ride = age >= 18 and height >= 150 and has_ticket   # 셋 다 만족?
print("롤러코스터 탑승 가능?", can_ride)   # True

3. if / if-else / if-elif-else#

# if-else 기본
i = 3
if i == 1:
    print("i는 1입니다.")
else:
    print("i는 1이 아닙니다.")   # i == 1 이 False → else 실행

# if-elif-else: 성적 판별
score = 78
if score >= 90:
    print("학점: A")
elif score >= 75:
    print("학점: B")    # 78 ≥ 75 → 여기서 멈춤
elif score >= 60:
    print("학점: C")
else:
    print("학점: F")

🔍 핵심 규칙

  • 조건 뒤에 반드시 콜론 :
  • 실행할 코드는 들여쓰기(4칸) 로 구분 — 파이썬의 핵심 문법
  • elif는 위에서부터 검사해 처음 True인 곳만 실행하고 멈춤
# 여러 if는 독립적으로 각각 검사됨 (elif와 차이!)
score = 75
if score >= 60:
    print("합격입니다! 🎉")   # 출력됨

if score >= 90:
    print("우수 합격입니다! 🏆")   # 안 출력 (75 < 90)

💡 elif vs 여러 if: elif는 하나만 골라 실행, 따로 쓴 if는 각각 독립적으로 검사합니다.

실용 예제 — BMI 계산기#

weight    = 70.0      # kg
height_cm = 175.0     # cm

height_m = height_cm / 100
bmi      = weight / (height_m ** 2)
print("BMI:", round(bmi, 2))   # 22.86

if bmi < 18.5:
    print("저체중입니다.")
elif bmi < 23:
    print("정상 체중입니다.")
elif bmi < 25:
    print("과체중입니다.")
else:
    print("비만입니다.")

💡 round(bmi, 2) → 소수점 둘째 자리까지 반올림.

홀짝 판별기#

number = 7
if number % 2 == 0:
    print(number, "은(는) 짝수입니다.")
else:
    print(number, "은(는) 홀수입니다.")

계절 판별기 — in 연산자#

month = 8
if month < 1 or month > 12:
    print("잘못된 입력입니다.")
elif month in [3, 4, 5]:
    print("봄입니다.")
elif month in [6, 7, 8]:
    print("여름입니다.")     # 8 in [6,7,8] → True
elif month in [9, 10, 11]:
    print("가을입니다.")
else:
    print("겨울입니다.")

💡 month in [6, 7, 8] → “month가 이 리스트 안에 있나?“를 한 번에 검사. 여러 번 ==로 비교하는 것보다 깔끔합니다.

간단한 계산기#

num1 = 10.0
op   = "/"      # +  -  *  /  중 하나
num2 = 3.0

if op == "+":
    print(num1, "+", num2, "=", num1 + num2)
elif op == "-":
    print(num1, "-", num2, "=", num1 - num2)
elif op == "*":
    print(num1, "*", num2, "=", num1 * num2)
elif op == "/":
    if num2 == 0:
        print("0으로 나눌 수 없습니다!")
    else:
        print(num1, "/", num2, "=", num1 / num2)
else:
    print("지원하지 않는 연산자입니다.")

💡 if 안에 또 if를 넣을 수 있습니다(중첩). 여기선 “나눗셈일 때, 그 중에서도 0으로 나누는지” 한 번 더 확인했어요.

Part 3. 리스트#

리스트는 여러 값을 순서대로 담는 그릇입니다. 추가·삭제·정렬이 자유로워요.

1. 핵심 메서드#

append(d) — 맨 끝에 추가#

a = []
a.append(10)
print(a)    # [10]

shopping = []
shopping.append("사과")
shopping.append("바나나")
shopping.append("우유")
print("장바구니:", shopping)   # ['사과', '바나나', '우유']

💡 append는 한 번에 하나만 추가합니다.

insert(i, d) — 원하는 위치에 삽입#

c = [1, 2, 4, 5]
c.insert(2, 3)           # 인덱스 2 자리에 3 삽입
print(c)                 # [1, 2, 3, 4, 5]

fruits = ["banana", "cherry"]
fruits.insert(0, "apple")  # 맨 앞(0번)에 삽입
print(fruits)              # ['apple', 'banana', 'cherry']

remove(d) — 값으로 삭제 (첫 번째 것만)#

my_list = [3, 1, 2, 3]
my_list.remove(3)
print(my_list)    # [1, 2, 3] ← 앞의 3만 삭제, 뒤의 3은 유지

⚠️ 없는 값을 remove하면 에러(ValueError). 먼저 if 값 in 리스트:로 확인하면 안전합니다.

sort() — 정렬#

e = [6, 2, 4, 1, 3, 5]
e.sort()
print(e)               # [1, 2, 3, 4, 5, 6]  오름차순

f = ["carrot", "apple", "banana"]
f.sort()
print(f)               # ['apple', 'banana', 'carrot']  사전순

g = [6, 2, 4, 1, 3, 5]
g.sort(reverse=True)
print(g)               # [6, 5, 4, 3, 2, 1]  내림차순

⚠️ sort()는 원본 리스트를 직접 바꾸고 아무것도 반환하지 않습니다(None). result = e.sort() 하면 result는 None이 되니 주의!

할 일(To-Do) 리스트 종합#

todo = ["운동하기", "책 읽기", "코딩 공부"]

todo.append("청소하기")        # 끝에 추가
todo.insert(0, "병원 예약")    # 맨 앞에 추가
todo.remove("운동하기")        # 완료 → 삭제
todo.sort()                    # 가나다순 정렬
print(todo)
# ['병원 예약', '책 읽기', '청소하기', '코딩 공부']

2. 시퀀스 자료형 공통 특징#

문자열(str)과 리스트(list)는 둘 다 순서가 있어서 공통 기능을 씁니다.

a = "Hello"
b = ["e", "l", "i", "c", "e"]

# 인덱싱 & 슬라이싱
print(a[1])      # e
print(b[2:4])    # ['i', 'c']

# in 연산자 (포함 여부)
print("e" in a)     # True
print("z" not in a) # True

# len() 길이
print(len("Hello World"))   # 11 (공백 포함)

# + 이어붙이기 / * 반복
print("Good" + "Day")        # GoodDay
print("Go!!" * 3)            # Go!!Go!!Go!!
print([13, 17] * 2)          # [13, 17, 13, 17]

str vs list 차이#

my_str  = "Python"
my_list = ['P','y','t','h','o','n']

print(my_str[0])    # P
print(my_list[0])   # P

my_list.append('!')   # 리스트는 추가 가능
print(my_list)        # ['P','y','t','h','o','n','!']
# my_str.append('!')  # ← 문자열은 append 불가! AttributeError
구분 str 문자열 list 리스트
값 변경 ❌ 불가(불변) ✅ 가능(가변)
append() ❌ ✅

Part 4. 시나리오 실습#

앞서 배운 자료형·조건문·리스트를 합쳐서 실전 문제를 풉니다. (for 반복문은 다음 시간 내용이지만 미리 등장)

시나리오 1 — 학생 성적 관리#

student_names  = ["Alice", "Bob", "Charlie", "David", "Eve"]
student_grades = [85, 72, 90, 65, 88]

print("총 학생 수:", len(student_names))

# 특정 학생 조회
target_idx = 2
print("조회 학생:", student_names[target_idx], student_grades[target_idx])  # Charlie 90

# 합격 여부 판별 (합격 기준 70점)
pass_score = 70
for i in range(len(student_names)):
    if student_grades[i] >= pass_score:
        status = "합격"
    else:
        status = "불합격"
    print(f"  {student_names[i]:<10} {student_grades[i]}점 → {status}")

# 성적 정렬 (원본 보존 위해 복사 후 정렬)
sorted_grades = student_grades[:]
sorted_grades.sort()
print("정렬된 성적:", sorted_grades)              # [65, 72, 85, 88, 90]
print("상위 3개:", sorted_grades[-3:])           # [85, 88, 90]

출력 일부:

  Alice      85점 → 합격
  Bob        72점 → 합격
  Charlie    90점 → 합격
  David      65점 → 불합격
  Eve        88점 → 합격

💡 student_grades[:] → 슬라이싱으로 원본을 복사. 정렬해도 원본은 그대로 둘 때 씁니다. f"{name:<10}" → 왼쪽 정렬로 10칸 너비 확보(표처럼 줄 맞춤).

시나리오 2 — 편의점 재고·매출 관리#

products = ["콜라", "과자", "라면", "물", "커피"]
prices   = [1500, 1200, 900, 800, 2000]   # 단가
stocks   = [10, 5, 3, 20, 7]              # 재고

# 재고 상태 표시
for i in range(len(products)):
    if stocks[i] == 0:
        status = "품절"
    elif stocks[i] <= 3:
        status = "부족"
    else:
        status = "정상"
    print(f"  {products[i]:<8} {prices[i]:>5}원  {stocks[i]:>3}개  {status}")

# 판매 처리 (라면 2개)
sold_idx, sold_qty = 2, 2
if stocks[sold_idx] >= sold_qty:
    stocks[sold_idx] -= sold_qty            # 재고 감소
    revenue = prices[sold_idx] * sold_qty
    print(f"판매 완료! 매출: {revenue:,}원")  # 1,800원

# 총 재고 가치
total_value = 0
for i in range(len(products)):
    total_value += prices[i] * stocks[i]
print(f"총 재고 가치: {total_value:,}원")

💡 {revenue:,} → 숫자에 천 단위 콤마(1800 → 1,800). {값:>3} 은 오른쪽 정렬 3칸.

시나리오 3 — 숫자 맞히기 게임 (로직)#

answer  = 47
guesses = [30, 60, 45, 50, 47]   # 추측 순서 (실제 게임은 input 사용)
history = []

for attempt, guess in enumerate(guesses, start=1):
    if guess == answer:
        result = "CORRECT!"
    elif guess < answer:
        result = "UP  (더 큰 수)"
    else:
        result = "DOWN (더 작은 수)"

    history.append((attempt, guess, result))   # 기록 저장
    print(f"  시도 {attempt}: {guess:>3} → {result}")

    if guess == answer:
        print(f"총 {attempt}번 만에 맞혔습니다!")
        break

💡 enumerate(guesses, start=1) → 리스트를 돌면서 번호(1,2,3…)와 값을 동시에 꺼냅니다. start=1이라 1번부터 셈.

시나리오 4 — 로그인 & 메뉴 시스템#

CORRECT_ID = "admin"
CORRECT_PW = "1234"

user_id = "admin"
user_pw = "1234"

if user_id == CORRECT_ID and user_pw == CORRECT_PW:
    print("로그인 성공!")
    is_logged_in = True
elif user_id == CORRECT_ID:
    print("비밀번호가 틀렸습니다.")
    is_logged_in = False
else:
    print("아이디가 틀렸습니다.")
    is_logged_in = False

# 로그인 성공 시 메뉴 표시
if is_logged_in:
    menu_items = ["회원 정보 조회", "비밀번호 변경", "로그아웃"]
    for idx, item in enumerate(menu_items, start=1):
        print(f"  {idx}. {item}")

    choice = 1
    valid_choices = list(range(1, len(menu_items) + 1))   # [1, 2, 3]
    if choice in valid_choices:
        selected = menu_items[choice - 1]    # 메뉴는 1번부터, 인덱스는 0부터 → -1
        print(f"선택: {choice}. {selected}")

💡 메뉴 번호(1,2,3)와 리스트 인덱스(0,1,2)가 1씩 차이 나서 choice - 1로 맞춥니다.
