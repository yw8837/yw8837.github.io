본격적으로 코딩을 시작하기 전에 개발 환경부터 갖춰야 합니다. 이번 과정에서는 uv라는 도구로 파이썬 환경을 세팅했어요. 설치부터 실행, 자주 막히는 부분까지 처음 하는 분도 따라올 수 있게 정리했습니다. 🛠️

⚠️ 아래 경로에 나오는 <사용자명> 부분은 본인 컴퓨터마다 다릅니다. 예시를 그대로 복사하지 말고, 화면에 출력된 본인 값을 사용하세요.

uv가 뭔가요?#

uv는 파이썬의 패키지·프로젝트 관리 도구입니다. 기존에 따로 쓰던 pip(패키지 설치) + venv(가상환경) + 버전 관리를 하나로 합쳐 놓은 것이라고 생각하면 됩니다. Rust로 만들어져서 설치·동기화가 매우 빠른 게 특징이에요.

💡 가상환경? 프로젝트마다 필요한 라이브러리 버전이 다릅니다. 가상환경은 프로젝트별로 독립된 작업 공간을 만들어, 라이브러리가 서로 충돌하지 않게 해줍니다. uv가 이걸 자동으로 만들어 줍니다.

공식 문서: docs.astral.sh/uv

1. uv 설치하기#

🪟 Windows#

  1. PowerShell을 “관리자 권한으로 실행” 합니다. (시작 버튼 → PowerShell 우클릭 → 관리자 권한으로 실행)
  2. 아래 명령어를 입력하고 Enter:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  1. 설치가 끝나면 uv.exe, uvx.exe, uvw.exe 가 깔리고, PATH(경로)를 추가하라는 안내가 출력됩니다. 화면에 나온 아래 형태의 줄을 복사해서 실행하세요:
$env:Path = "C:\Users\<사용자명>\.local\bin;$env:Path"

⚠️ 이 줄은 사용자마다 경로가 다릅니다! 위 예시를 그대로 쓰지 말고, 본인 화면에 출력된 줄을 복사하세요. 💡 PowerShell에서는 복사가 Ctrl + Insert, 붙여넣기가 Shift + Insert 입니다. (일반 Ctrl+C/V가 안 먹힐 때)

📌 PATH가 뭐죠? 컴퓨터가 “uv 명령어가 어느 폴더에 있는지” 찾는 길 목록입니다. 여기에 uv 설치 폴더를 등록해야 어디서든 uv 명령을 쓸 수 있어요.

🍎 macOS#

터미널을 열고 아래를 실행합니다:

curl -LsSf https://astral.sh/uv/install.sh | sh

공식 문서 Installation 페이지에서 OS 탭(macOS)을 선택하면 정확한 명령을 확인할 수 있습니다.

2. 설치 잘 됐는지 확인#

uv --version

아래처럼 버전이 출력되면 성공입니다.

uv 0.11.16 (... x86_64-pc-windows-msvc)

3. 프로젝트 설정 파일 준비#

강의에서 제공한 uv_project_settings.zip 파일의 압축을 풉니다. 안에는 이런 파일들이 들어 있어요:

파일역할
pyproject.toml이 프로젝트에 필요한 패키지 목록
uv.lock패키지들의 정확한 버전 고정 (누구나 똑같은 환경 재현)
check_env.py환경이 잘 깔렸는지 확인하는 스크립트
.gitignore, env.example 등기타 설정

💡 pyproject.toml + uv.lock 덕분에, 팀원 누구나 uv sync 한 번이면 완전히 똑같은 환경을 만들 수 있습니다.

4. 의존성 설치 — uv sync#

  1. VS Code를 관리자 권한으로 실행합니다.
  2. 압축 푼 프로젝트 폴더를 열고, 터미널을 켭니다. (Windows: PowerShell / macOS: bash)
  3. 아래를 실행:
uv sync

그러면 .venv 라는 가상환경 폴더가 생기고, 필요한 패키지들이 좌르륵 설치됩니다.

Creating virtual environment at: .venv
Using CPython 3.13.2
Resolved 117 packages
Installed 114 packages
 + numpy==2.4.6
 + pandas==3.0.3
 + matplotlib==3.10.9
 ... (생략)

Installed N packages 가 에러 없이 나오면 성공입니다. 🎉

5. 환경 확인 — check_env.py 실행#

설치가 제대로 됐는지 확인하는 스크립트를 실행해 봅니다.

uv run python check_env.py

💡 uv run <명령> 은 “uv가 만든 가상환경 안에서 그 명령을 실행해줘” 라는 뜻입니다. 가상환경을 따로 켤(activate) 필요가 없어서 편해요.

정상이라면 아래처럼 라이브러리 버전이 출력됩니다.

6. JupyterLab 실행#

실습은 주로 JupyterLab(주피터랩)에서 진행합니다. 아래 명령으로 실행하세요.

uv run jupyter lab

잠시 후 브라우저에서 JupyterLab이 자동으로 열립니다. 이제 코드를 셀 단위로 실행하며 실습할 수 있어요.

7. ⚠️ 안 될 때 — Windows 보안 차단 해결#

Windows에서 uv run 을 했는데 아래 같은 에러가 나는 경우가 있습니다.

error: Failed to spawn: `python`
  Caused by: 애플리케이션 제어 정책에서 이 파일을 차단했습니다. (os error 4551)

이건 Windows 보안 기능이 python 실행을 막아서 생기는 문제입니다.

해결 방법

  1. 작업표시줄 검색에서 “Windows 보안” 검색 → 실행
  2. 앱 및 브라우저 컨트롤 항목으로 이동
  3. 차단하는 설정(평판 기반 보호 / 스마트 앱 컨트롤 등)을 잠시 해제
  4. 다시 uv run python check_env.py 실행

⚠️ 이건 컴퓨터를 지켜주는 보안 기능입니다. 설치·확인 작업이 끝나면 다시 켜두는 것을 권장합니다.

자주 쓰는 uv 명령 정리#

명령역할
uv --versionuv 버전 확인
uv syncpyproject.toml·uv.lock 기준으로 패키지 설치
uv run <명령>가상환경 안에서 명령 실행 (uv run python a.py)
uv add <패키지>새 패키지 추가

마무리#

환경 설정은 처음 한 번이 제일 막막하지만, 핵심은 단 두 줄입니다 — 설치(install) → 동기화(uv sync). 그다음부터는 uv run 으로 코드를 돌리기만 하면 돼요. 막히면 7번 보안 항목을 먼저 확인해 보세요. 💪
