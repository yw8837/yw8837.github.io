내가 만든 패키지를 PyPI에 실제로 배포하는 전 과정을 손으로 따라가는 실습 노트입니다. 예제 패키지는 수업에서 다룬 **mathlib-evanjjh**예요. 이론은 라이브러리 활용 강의 노트에서, 여기서는 명령·코드 중심으로 갑니다. 📦

ℹ️ 수업 중 라이브 배포 시연은 인증 메일 문제로 실패했지만, 패키지 자체는 실제 PyPI에 존재합니다(pip install mathlib-evanjjh 시 0.1.5 설치). 아래 흐름은 그 실제 결과물 기준입니다. 🔒 토큰·이메일은 모두 **자리표시자(예제값)**입니다. 실제 값을 그대로 쓰지 마세요.

0. 준비물 — PyPI 계정 & API 토큰#

① pypi.org 회원가입 → 계정 설정 → API tokens → “Add API token”

② 토큰 이름(예: mathlib-evanjjh), scope는 전체 계정으로 발급

③ 발급된 토큰은 pypi-...로 시작하며 한 번만 표시됩니다 → 즉시 복사해 안전하게 보관

💡 토큰을 놓쳤다면 새로 발급하면 됩니다. 이전 토큰은 폐기(revoke)하세요.

1. GitHub repo 만들기#

항목값
이름mathlib-evanjjh
공개Public
.gitignorePython

💡 .gitignore를 Python으로 잡아두면 .venv, __pycache__, dist/ 같은 게 자동으로 커밋에서 제외됩니다. 뒤에서 .pypirc도 반드시 무시 대상에 넣어야 해요.

2. src 레이아웃 디렉터리 구조#

① 패키지는 src/ 아래에 두는 “src 레이아웃"으로 구성합니다.

mathlib-evanjjh/
├─ src/
│  └─ mathlib_evanjjh/
│     ├─ __init__.py
│     ├─ arithmetic.py
│     ├─ geometric.py        # 실제 배포본에 포함 (소스는 이 노트 범위 밖)
│     └─ trigonometry.py     # 실제 배포본에 포함 (소스는 이 노트 범위 밖)
├─ tests/
│  ├─ __init__.py
│  └─ test_arithmetic.py
├─ pyproject.toml
└─ README.md

④ 한 줄씩 뜯어보기

  • src/mathlib_evanjjh/ — 실제 패키지 코드. 폴더명은 언더스코어(import 이름).
  • tests/ — pytest 테스트 코드.
  • pyproject.toml — 빌드·메타정보 설정.

⚠️ 배포명은 하이픈 mathlib-evanjjh, import명은 언더스코어 mathlib_evanjjh. 파이썬 import 구문에 하이픈을 못 쓰기 때문입니다.

3. uv로 초기화 + 개발 도구 설치#

① 프로젝트 골격을 만들고, 테스트·업로드 도구를 개발 의존성으로 추가합니다.

uv init .                    # pyproject.toml 등 기본 골격 생성
uv add --dev pytest twine    # 테스트(pytest)·업로드(twine) 도구 추가

④ 한 줄씩 뜯어보기

  • uv init . — 현재 폴더를 uv 프로젝트로 초기화.
  • uv add --dev pytest twine — --dev는 “개발할 때만 필요"라는 뜻. 패키지 사용자에겐 필요 없으니 개발 의존성으로 분리.

💡 uv는 pip install -r requirements.txt보다 훨씬 빠릅니다. 구형 PC에서 수십 분 걸리던 설치가 크게 단축돼요.

4. pyproject.toml 작성 (hatchling 빌드)#

① 패키지 이름·버전·빌드 백엔드 등 메타정보를 정의합니다.

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[project]
name = "mathlib-evanjjh"
version = "0.1.0"
authors = [{ name = "EvanJJH", email = "you@example.com" }]
description = "A class-based Python utility package for arithmetic, geometric sequences, and trigonometry"
readme = "README.md"
requires-python = ">=3.8"

④ 한 줄씩 뜯어보기

  • [build-system] — 빌드 도구로 hatchling 지정.
  • name — PyPI에 올라갈 배포명(하이픈).
  • version — 핵심! 바꿀 때마다 올린다 (5번 참고).
  • requires-python — 지원 파이썬 최소 버전.

🔒 email은 예제값 you@example.com입니다. 실제 배포 시 본인 메일을 넣되, 공개 저장소임을 감안하세요.

5. .pypirc 인증 파일 (🔒 git 커밋 절대 금지)#

① 홈 디렉터리에 ~/.pypirc를 만들어 토큰을 넣습니다.

[pypi]
username = __token__
password = pypi-...        # 0번에서 발급받은 토큰 (자리표시자)

④ vi로 작성하기

  • i → 입력 모드 진입
  • 위 내용 작성
  • Esc → :wq → 저장 후 종료

🔒 .pypirc는 절대 git에 커밋하지 마세요. 토큰이 노출되면 누구나 여러분 이름으로 패키지를 올릴 수 있습니다. .gitignore에 포함됐는지 꼭 확인하세요.

6. Arithmetic 클래스 작성#

① 사칙연산을 클래스로 묶습니다. 0으로 나누면 에러를 냅니다.

# src/mathlib_evanjjh/arithmetic.py
class Arithmetic:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def add(self):
        return self.a + self.b

    def subtract(self):
        return self.a - self.b

    def multiply(self):
        return self.a * self.b

    def divide(self):
        if self.b == 0:
            raise ValueError("0으로 나눌 수 없습니다.")
        return self.a / self.b

④ 한 줄씩 뜯어보기

  • __init__(self, a, b) — 두 숫자를 받아 인스턴스에 저장.
  • add/subtract/multiply — 사칙연산 반환.
  • divide — b == 0이면 ValueError를 던져 0으로 나누기를 막음.

ℹ️ geometric(등비수열)·trigonometry(삼각함수) 모듈도 실제 배포본에 들어 있지만 수업 자료에 소스가 없어 코드는 생략합니다. 사용법(시그니처·출력)만 9번에서 확인하세요.

7. pytest 테스트 작성 & 실행#

① 클래스가 의도대로 동작하는지 검증합니다.

# tests/test_arithmetic.py
import pytest
from mathlib_evanjjh.arithmetic import Arithmetic

class TestArithmetic:
    def test_add(self):
        assert Arithmetic(3, 2).add() == 5

    def test_subtract(self):
        assert Arithmetic(10, 4).subtract() == 6

    def test_multiply(self):
        assert Arithmetic(3, 7).multiply() == 21

    def test_divide(self):
        assert Arithmetic(10, 2).divide() == 5.0

    def test_divide_by_zero(self):
        with pytest.raises(ValueError):
            Arithmetic(5, 0).divide()

② 실행:

uv run pytest        # (또는 pytest)

④ 한 줄씩 뜯어보기

  • from mathlib_evanjjh.arithmetic import Arithmetic — import명(언더스코어) 사용.
  • assert ... == 값 — 결과가 기대값과 같은지 확인.
  • with pytest.raises(ValueError): — divide(0)이 정말 에러를 내는지까지 검증.

💡 테스트가 통과한 코드만 배포합니다. 통과를 못 하면 업로드로 넘어가지 마세요.

8. ★ 버전 올리며 twine으로 업로드#

① 빌드 결과물(dist/*)을 PyPI에 올립니다.

uv run twine upload dist/*     # (또는 twine upload dist/*)

② 핵심은 버전 지속 업데이트입니다.

  • 기능을 바꿀 때마다 pyproject.toml의 version을 올립니다. 개념상 예시: 0.1.0 → 0.2.0 → 0.3.0 …
  • 같은 버전은 재업로드 불가 → 바꿨으면 무조건 bump.
  • 이번 mathlib-evanjjh는 실제로 0.1.5까지 도달했습니다.

💡 “개념 예시 버전(0.1.0→0.2.0→0.3.0)“과 “실제 도달 버전(0.1.5)“은 별개입니다. 외울 건 숫자가 아니라 **“바꿀 때마다 올린다”**는 원칙. 💡 표준 도구만 쓰는 대안: pip install build twine → python -m build → twine upload dist/*. 이번 수업 메인은 uv + hatchling + twine. 💡 처음엔 TestPyPI에 먼저 올려 연습하면 안전합니다.

9. 설치 & 작동 확인 (배포 후, 3모듈 전체)#

① 배포된 패키지를 받아 잘 동작하는지 확인합니다.

!pip install mathlib-evanjjh        # → mathlib_evanjjh-0.1.5 설치 확인

② 세 모듈을 import해 동작 확인:

from mathlib_evanjjh.arithmetic import Arithmetic
from mathlib_evanjjh.geometric import GeometricSequence
from mathlib_evanjjh.trigonometry import Trigonometry

calc = Arithmetic(10, 2)
print(calc.add())       # 12
print(calc.subtract())  # 8
print(calc.multiply())  # 20
print(calc.divide())    # 5.0

gs = GeometricSequence(first=1, ratio=2, n=5)
print(gs.generate())    # [1, 2, 4, 8, 16]
print(gs.nth_term(3))   # 4
print(gs.sum())         # 31.0

print(Trigonometry(30).sin())   # 0.5
print(Trigonometry(60).cos())   # 0.5
print(Trigonometry(45).tan())   # 1.0

④ 한 줄씩 뜯어보기

  • Arithmetic(10, 2) — 6~7번에서 만든 클래스. 사칙연산 확인.
  • GeometricSequence(first, ratio, n) — 등비수열 생성/특정 항/합. 시그니처·출력만 인용 (내부 구현은 자료에 없음).
  • Trigonometry(각도).sin()/cos()/tan() — 도(degree) 단위 삼각함수. 역시 시그니처·출력만 인용.

ℹ️ GeometricSequence·Trigonometry의 내부 구현 코드는 수업 자료에 없습니다. 위 사용법은 테스트 노트북의 실제 출력 기준이며, 구현을 지어내지 않았습니다. [원문 확인 필요: geometric/trigonometry 소스]

📚 보충#

PyPI · 패키징 가이드 · uv 문서 · pytest 문서 기반.

  • uv run X — uv가 만든 가상환경 안에서 X를 실행. 환경 활성화 없이 바로 도구 사용 가능.
  • 버전 재업로드 불가 — 실수로 올렸어도 같은 번호로 덮어쓰기 안 됨. 다음 패치로 올려야 함.
  • TestPyPI — 연습용 별도 저장소. 실서비스에 영향 없이 배포 흐름을 시험할 수 있음.
