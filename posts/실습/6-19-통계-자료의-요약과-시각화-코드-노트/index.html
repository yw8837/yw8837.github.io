!sudo apt-get install -y -qq fonts-nanum

④ apt-get으로 나눔폰트를 설치한다. seaborn tips는 인터넷에서 받으므로 drive.mount가 필수는 아니지만, 노트북은 산출물 저장 등을 위해 마운트한다. ⑤ 💡 설치만 하고 런타임을 재시작하지 않으면 여전히 깨진다. 폰트 캐시는 런타임 시작 시 한 번 읽히기 때문 — 설치 → 세션 다시 시작 → 폰트 적용 셀 순서를 지킨다. 어제 pandas 실습에서도 똑같이 강조된 포인트다.

② matplotlib에 한글 폰트를 적용하고, 마이너스 기호 깨짐을 막는다. (출처: viz_basic_01.ipynb 셋업 셀 — set_nanum_gothic())

import platform
import matplotlib.pyplot as plt
from matplotlib import font_manager

def set_nanum_gothic():
    plt.rcParams["axes.unicode_minus"] = False     # 음수 축 라벨의 - 깨짐 방지
    if platform.system() == "Windows":
        plt.rcParams["font.family"] = "Malgun Gothic"
    else:
        # Linux(Colab): 설치된 NanumGothic 탐색·등록
        for p in font_manager.findSystemFonts():
            if "Nanum" in p:
                font_manager.fontManager.addfont(p)
        plt.rcParams["font.family"] = "NanumGothic"

set_nanum_gothic()

③ 출력 (Colab 기준):

적용 폰트: NanumGothicCoding

⑤ 💡 axes.unicode_minus = False를 빼면 음수 축 라벨의 마이너스가 네모로 깨진다 — 산포·편차를 다루는 오늘 같은 통계 차트에서 특히 잘 보인다.

# 연속형 / 이산형 / 명목형 / 순위형으로 분류
print("day  :", tips['day'].cat.categories.tolist())

③ 출력:

day  : ['Thur', 'Fri', 'Sat', 'Sun']

④ 분류 결과 — 연속형(total_bill, tip), 이산형(size 1~6명), 명목형(sex, smoker, time), 순위형(day: Thur<Fri<Sat<Sun, 요일 순서가 의미 있음). ⑤ 💡 같은 “범주형"이라도 day처럼 순서가 있으면 순위형, sex처럼 순서가 없으면 명목형이다. 순서 정보는 정렬·구간화에서 쓸모가 있어 구분해 둔다.

02 · 도수분포표 · 교차표 (value_counts · crosstab)#

① 범주형은 개수(도수)와 비율(상대도수)로 요약한다. (출처: viz_basic_01.ipynb cell 8)

tips['day'].value_counts()                  # 요일별 도수
tips['day'].value_counts(normalize=True)    # 요일별 상대도수(비율)
pd.crosstab(index=tips['day'], columns=tips['smoker'])   # 요일 × 흡연 교차표

③ 출력 (요일별 도수 / 상대도수):

day
Sat     87
Sun     76
Thur    62
Fri     19

Sat     0.357
Sun     0.311
Thur    0.254
Fri     0.078

④ value_counts()는 도수(개수), normalize=True는 상대도수(전체 대비 비율)다. pd.crosstab은 두 범주를 가로·세로로 교차해, 셀마다 “두 범주를 동시에 만족하는 건수"를 센다(요일×흡연: Sat 흡연42/비흡연45 등). ⑤ 💡 상대도수의 합은 항상 1.0(=100%)이다. 표본 크기가 다른 그룹을 비교할 땐 도수(개수)보다 상대도수(비율)가 공정하다.

03 · 원형 + 막대그래프#

① 같은 요일 도수를 원형(비율)과 막대(크기)로 나란히 그려 차이를 본다. (출처: viz_basic_01.ipynb cell 10)

fig, axes = plt.subplots(1, 2, figsize=(11, 4))
counts = tips['day'].value_counts()
axes[0].pie(counts.values, labels=counts.index, autopct="%1.1f%%")   # 원형: 비율
axes[1].bar(counts.index.astype(str), counts.values)                 # 막대: 크기
plt.show()

③ 출력: [출력 생략: 2분할 차트 — 좌 원형(요일 비율), 우 막대(요일 도수)] ④ 왼쪽 원형은 autopct로 비율(%)을 표시, 오른쪽 막대는 도수(개수)를 높이로 표시한다. 같은 데이터인데 원형은 “비율”, 막대는 “크기 비교"가 잘 보인다. ⑤ 💡 처음부터 fig, axes = plt.subplots(1, 2)로 그릴 칸 2개를 명시적으로 잡고 axes[0]·axes[1]에 따로 그린다 — §13에서 설명할 객체지향 방식이다.

04 · 수치형 도수분포표(Sturges) + 히스토그램·도수다각형#

① 연속형(total_bill)은 값을 구간(계급)으로 묶어 분포를 본다. 계급 수는 Sturges 공식 $k=1+\log_2 n$으로 정한다. (출처: viz_basic_01.ipynb cell 12)

import numpy as np
n = len(tips)
k = int(np.ceil(1 + np.log2(n)))              # Sturges: 계급 수(올림)
rng = tips['total_bill'].max() - tips['total_bill'].min()   # 범위
width = np.ceil(rng / k)                       # 계급폭
print(f"최소 {tips['total_bill'].min():.2f}, 최대 {tips['total_bill'].max():.2f}, 범위 {rng:.2f}")
print(f"계급 수 {k}, 계급폭 {width}")

③ 출력:

최소 3.07, 최대 50.81, 범위 47.74
계급 수 9, 계급폭 6.0

도수분포표 (계급 / 도수):

3~9 (10), 9~15 (67), 15~21 (78, 최다), 21~27 (41), 27~33 (24),
33~39 (12), 39~45 (7), 45~51 (4), 51~57 (1)

④ 1+log2(244) ≈ 8.9 → 9계급, 범위 47.74를 9로 나눠 올림하면 계급폭 6. 가장 도수가 많은 구간은 15~21(78건)이다. ⑤ 💡 Sturges는 “데이터 양에 맞춰 계급 수를 자동으로 정하는” 경험식이다. 계급을 너무 잘게 쪼개면 들쭉날쭉하고, 너무 크게 묶으면 모양이 뭉개진다 — Sturges가 그 절충점을 준다.

① 도수분포표를 히스토그램과 도수다각형으로 그린다. (출처: viz_basic_01.ipynb cell 14·16)

fig, ax = plt.subplots(figsize=(7, 4))
counts, bins, _ = ax.hist(tips['total_bill'], bins=k)        # 히스토그램
bin_mids = (bins[:-1] + bins[1:]) / 2                        # 각 계급 중앙
ax.plot(bin_mids, counts, marker="o")                       # 도수다각형(꺾은선)
plt.show()

③ 출력: [출력 생략: 히스토그램 막대 + 도수다각형 꺾은선 / cell 16은 흡연·비흡연 두 그룹 도수다각형 겹쳐 비교] ④ 히스토그램은 계급별 도수를 막대로, 도수다각형은 각 계급 중앙(bin_mids) 에 점을 찍어 직선으로 잇는다. cell 16은 흡연/비흡연 두 그룹의 도수다각형을 겹쳐 분포를 비교한다. ⑤ 💡 여러 그룹 비교는 도수다각형이 유리하다 — 막대(히스토그램)를 두 그룹 겹치면 서로 가리지만, 꺾은선은 겹쳐도 둘 다 보인다.

05 · 산점도 — 두 연속형 변수의 관계#

① total_bill과 tip의 관계를 점으로 본다(시간대별 색 구분). (출처: viz_basic_01.ipynb cell 18)

fig, ax = plt.subplots(figsize=(6, 4))
sns.scatterplot(data=tips, x="total_bill", y="tip", hue="time", ax=ax)
plt.show()

③ 출력: [출력 생략: 산점도 — total_bill↑일수록 tip↑ 경향, Lunch/Dinner 색 구분] ④ sns.scatterplot에 ax=ax로 그릴 칸을 지정한다(seaborn은 ax= 인자를 받는다 — 안 주면 레이아웃이 깨질 수 있다). hue="time"은 식사시간으로 점 색을 나눈다. ⑤ 💡 상관계수(§12)를 구하기 전에 항상 산점도부터 본다 — 점이 좌하→우상으로 퍼지면 양의 관계, 곡선이거나 이상값이 있으면 상관계수 숫자만 믿으면 안 된다(어제 앤스컴 콰르텟).

06 · 중심위치 측도 (mean · median · mode)#

① 평균·중앙값·최빈값을 계산하고 axvline으로 표시한다. (출처: viz_basic_01.ipynb cell 21)

from scipy import stats
mean_v   = tips['total_bill'].mean()
median_v = tips['total_bill'].median()
mode_v   = stats.mode(tips['total_bill'], keepdims=False).mode
print(f"평균 {mean_v:.2f}, 중앙값 {median_v:.2f}, 최빈값 {mode_v:.2f}")
# mean > median → right-skewed(오른쪽 꼬리)   ← 코드 주석(영어 skew 기준)

③ 출력:

평균 19.79, 중앙값 17.80, 최빈값 13.42

④ 평균은 모든 값을 반영(극단값에 민감), 중앙값은 정렬 후 가운데(강건), 최빈값은 가장 잦은 값이다. 세 값이 다르니 total_bill은 비대칭 분포다. ⑤ 💡 ⚠ “치우친 분포” 라벨이 자료 안에서 충돌한다 — 두 관례로 분리한다.

  • (A) 봉우리 기준(논리 PDF p19 슬라이드 + 노트북 마크다운): “왼쪽으로 치우친 분포 → 평균 > 중앙값”.
  • (B) 꼬리 기준(위 코드 주석, 영어 skewness): “오른쪽 꼬리(right-skewed) → 평균 > 중앙값”.

두 관례는 “치우쳤다"의 방향을 반대로 정의한다(봉우리 왼쪽 = 꼬리 오른쪽). 그래서 “평균(19.79) > 중앙값(17.80)“이라는 수치 관계 자체는 둘 다 동일하고, 같은 분포를 (A)는 “왼쪽 치우침”, (B)는 “right-skewed"라 부를 뿐이다. 혼동을 피하려면 방향 라벨 대신 “평균 > 중앙값"이라는 수치 관계로 말하는 게 안전하다. (원천 자료가 두 라벨을 오가므로 강사 확인 필요 — 지어내지 않는다.)

07 · 산포 측도 (var · std · range · IQR · CV)#

① 퍼진 정도를 다섯 가지로 잰다. (출처: viz_basic_01.ipynb cell 23)

x = tips['total_bill']
var_v   = x.var(ddof=1)                 # 표본분산 (n-1)
std_v   = x.std(ddof=1)                 # 표본표준편차
range_v = x.max() - x.min()             # 범위
Q1, Q3  = x.quantile(0.25), x.quantile(0.75)
iqr_v   = Q3 - Q1                        # IQR = Q3 - Q1
cv_v    = std_v / x.mean() * 100         # 변동계수(%)
print(f"분산 {var_v:.2f}, 표준편차 {std_v:.2f}, 범위 {range_v:.2f}")
print(f"IQR {iqr_v:.2f} (Q1 {Q1:.2f}, Q3 {Q3:.2f}), 변동계수 {cv_v:.1f}%")

③ 출력:

분산 79.25, 표준편차 8.90, 범위 47.74
IQR 10.78 (Q1 13.35, Q3 24.13), 변동계수 45.0%

④ ddof=1은 표본분산(n−1로 나눔, 불편추정량). IQR은 Q3−Q1로 가운데 50%의 폭이라 극단값 영향이 없다. 변동계수는 표준편차÷평균×100(%)으로 단위가 없다. ⑤ 💡 노트북 실행 시 FutureWarning: groupby observed=False ... deprecated가 뜰 수 있다 — 동작에는 문제없고, 향후 버전 대비 groupby(..., observed=True) 명시를 권장한다는 경고다.

08 · 백분위수 (Percentile)#

① 하위 p% 지점의 값을 구한다. (출처: viz_basic_01.ipynb cell 25)

ps = [10, 25, 50, 75, 90]
vals = np.percentile(tips['total_bill'], ps)
for p, v in zip(ps, vals):
    print(f"P{p} = {v:.2f}")

③ 출력:

P10 = 10.34
P25 = 13.35
P50 = 17.80
P75 = 24.13
P90 = 32.24

④ P25·P50·P75는 각각 Q1·중앙값·Q3와 같다. IQR(Q1~Q3) 구간을 음영으로 표시하면 “가운데 50%가 어디에 모여 있나"가 보인다. ⑤ 💡 백분위수는 사분위수(25·50·75)의 일반화다 — P10·P90까지 보면 양 끝 꼬리가 얼마나 멀리 있는지 가늠된다.

09 · 상자그림 (boxplot)#

① 다섯 수치 요약(최솟값·Q1·Q2·Q3·최댓값)을 상자와 수염으로 그린다. (출처: viz_basic_01.ipynb cell 27)

fig, axes = plt.subplots(1, 2, figsize=(11, 4))
sns.boxplot(data=tips, x="day", y="total_bill", ax=axes[0])   # 요일별 결제액
sns.boxplot(data=tips, x="smoker", y="tip", ax=axes[1])       # 흡연별 팁
plt.show()

③ 출력: [출력 생략: 2분할 상자그림 — 좌 요일별 total_bill, 우 흡연별 tip] ④ 상자 = Q1~Q3(IQR), 상자 안 선 = 중앙값, 수염 = Q1−1.5×IQR ~ Q3+1.5×IQR, 그 바깥 점 = 이상값이다. ⑤ 💡 상자그림 전에 히스토그램으로 분포 모양을 먼저 본다 — 봉우리가 둘인 분포(다봉형)도 상자그림에선 멀쩡한 상자 하나로 보여 오해를 부르기 때문이다.

10 · 도수분포표 기반 요약 (midpoint 가정)#

① 원 자료 대신 도수분포표만 있다고 보고, 각 계급의 중간값(midpoint) 으로 평균·표준편차를 근사한다. (출처: viz_basic_01.ipynb cell 29)

# §04에서 만든 계급(counts, bins) 재사용
mids = (bins[:-1] + bins[1:]) / 2                 # 계급 중간값
grp_mean = np.sum(mids * counts) / counts.sum()   # 그룹 평균 = Σ(중간값×도수)/n
grp_std  = np.sqrt(np.sum((mids - grp_mean)**2 * counts) / (counts.sum() - 1))
print(f"그룹 평균 {grp_mean:.2f} (원자료 19.79)")
print(f"그룹 표준편차 {grp_std:.2f} (원자료 8.90)")

③ 출력:

그룹 평균 19.66 (원자료 19.79)
그룹 표준편차 8.95 (원자료 8.90)

④ 그룹화하면 구간 안의 세밀한 값이 중간값 하나로 뭉뚱그려진다. 그래서 그룹 평균(19.66)이 원자료 평균(19.79)과 미세하게 어긋난다. ⑤ 💡 이 차이가 “정보 손실"의 증거다. 원 자료를 쓸 수 있으면 항상 원 자료로, 도수분포표 요약은 원 자료가 없을 때의 차선이다.

12 · 공분산 · 상관계수 (r = 0.6757)#

① 두 연속형 변수의 관계 강도를 수치로 잰다. (출처: viz_basic_01.ipynb cell 33)

r     = tips[['total_bill','tip']].corr().iloc[0, 1]   # 피어슨 상관계수
print(f"공분산 {cov_v:.4f}, 상관계수 r = {r:.4f}")
tips[['total_bill','tip','size']].corr()               # 상관행렬

③ 출력:

공분산 8.3235, 상관계수 r = 0.6757
# 상관행렬
              total_bill    tip   size
total_bill         1.000  0.676  0.598
tip                0.676  1.000  0.489
size               0.598  0.489  1.000

④ 공분산은 단위가 있어 크기 해석이 어렵지만, 상관계수 r은 −1~1로 표준화돼 비교가 쉽다. total_bill–tip r=0.68(양의 상관) — 결제액이 클수록 팁도 느는 경향. ⑤ 💡 ⚠ “상관계수 높음 ≠ 인과관계” — 노트북 캡션이 강조한 그대로다. r이 커도 산점도(§05)로 모양을 먼저 확인하고, 숨은 공통 원인(교란 변수)을 의심해야 한다. 상관계수는 직선 관계만 재므로 곡선 관계는 r≈0이 나올 수 있다.

② Okabe-Ito 색 팔레트 셋업 — 노트북 전체에서 같은 범주에 같은 색을 쓰기 위한 공통 정의. (출처: viz_basic_01.ipynb 셋업 셀)

PALETTE_OI = ["#E69F00","#56B4E9","#009E73","#F0E442",
              "#0072B2","#D55E00","#CC79A7","#000000"]   # Okabe-Ito (색각이상 안전)
COLOR_SEQ = "#0072B2"        # 연속형·분포 = 단일 청색
COLOR_EMPHASIS = "#D55E00"   # 강조 = vermillion (한 그래프에 하나만)

def stable_cat_colors(values, palette=PALETTE_OI):
    cats = sorted(pd.Series(values).dropna().unique())
    return {c: palette[i % len(palette)] for i, c in enumerate(cats)}

⑤ 💡 stable_cat_colors()는 범주를 정렬해 팔레트에 1:1 매핑한다 — 차트가 바뀌어도 “흡연자=항상 같은 색"이 유지돼, 여러 차트를 색만 보고 넘나들며 읽을 수 있다.

15 · (당일 라이브 보충) Categorical fillna 에러 → astype(‘object’)#

📎 출처: 6/19 라이브 노션 메모(_notion_0619.md). 6/18 pandas 실습의 당일 보충. (노션 원본은 코드 언어를 javascript로 표기했으나 실제 Python이다.)

① category dtype 컬럼에 새 카테고리로 fillna하면 에러가 난다. object로 바꾼 뒤 채워야 한다. (출처: _notion_0619.md)

df = titanic.copy()
print(df.info())
df['deck'] = df['deck'].astype('object')   # category → object 변환
print("---변경---")
print(df.info())
# df['deck'] = df['deck'].fillna('ABC')     # object로 바꾼 뒤엔 OK

③ 변환 전 fillna('ABC')를 시도하면 나는 에러:

TypeError: Cannot setitem on a Categorical with a new category (ABC), set the categories first

④ category dtype은 미리 정해진 카테고리 집합만 허용한다. 거기 없는 새 값(‘ABC’)을 넣으려니 거부한다. astype('object')로 일반 문자열 컬럼으로 바꾸면 자유롭게 채울 수 있다. ⑤ 💡 강사 정리 — 방법1=카테고리를 먼저 등록(복잡해서 잘 안 씀) / 방법2=dtype을 object로 변경(권장). §00에서 tips의 sex/smoker/day/time이 전부 category였던 것을 떠올리면, 이 에러가 왜 흔한지 보인다.

16 · (당일 라이브 보충) assign 파생변수 — 문제47#

① assign으로 cpu/memory/disk 사용량을 합한 파생변수를 만든다. (출처: _notion_0619.md)

dr_srv.assign(usage_sum = dr_srv['cpu_usage'] + dr_srv['memory_usage'] + dr_srv['disk_usage'])[['cpu_usage', 'disk_usage', 'memory_usage', 'usage_sum']].head()

④ assign(새컬럼 = 식)은 원본을 건드리지 않고 새 컬럼이 추가된 복사본을 반환한다. 뒤의 [[...]]로 확인할 컬럼만 골라 head()로 본다. ⑤ 💡 강사는 “개인적으로는 비추"라고 했다 — df['usage_sum'] = ... 직접 대입이 더 직관적이라는 취지. 다만 assign은 메서드 체이닝(.assign().query().groupby()처럼 끊김 없이 잇기)에 유리해 상황에 따라 쓴다.

📎 노트북 미커버 항목. 점도표(dot diagram)·줄기-잎그림(stem-leaf)·“분포의 모양"은 시각화 PDF 교안에만 있고 viz_basic_01에는 코드 구현이 없어 본 코드 노트에서도 다루지 않는다(강의정리에 이론으로만 소개). 히스토그램·도수다각형은 §04에 구현되어 있다.

마무리#

오늘 실습은 seaborn tips(244건)로 통계 요약의 전 과정을 코드로 돌렸다. 줄기는 — 환경설정(Colab 한글폰트 설치+재시작)을 통과하고, 자료형 분류(cell 6) → 도수분포표·교차표(cell 8) → 원형·막대(cell 10) → Sturges 도수분포표·히스토그램·도수다각형(cell 12·14·16) → 산점도(cell 18) → 중심위치(평균 19.79·중앙값 17.80·최빈값 13.42, cell 21) → 산포(표준편차 8.90·IQR 10.78·변동계수 45%, cell 23) → 백분위수(cell 25) → 상자그림(cell 27) → 도수분포표 midpoint 요약(그룹 19.66 vs 원자료 19.79, cell 29) → 분할표(cell 31) → 공분산·상관(r=0.6757, cell 33)이다. 도구로는 fig, ax 객체지향과 Okabe-Ito 색 셋업(동일 범주=동일 색)을 익혔다. 두 가지를 정직하게 표시했다 — “치우친 분포"의 평균–중앙값은 봉우리/꼬리 두 관례로 갈리니 수치 관계(“평균>중앙값”)로 말한다, 그리고 점도표·줄기잎그림은 PDF 이론에만 있고 코드 구현이 없다. 당일 라이브 보충 2건(Categorical fillna 에러 → astype('object'), assign 파생변수)도 함께 정리했다. 한 줄 결론 — 요약 수치는 반드시 그림(산점도·히스토그램)으로 교차 확인하고, 상관은 인과가 아니다.
