01 · 독립표본 t검정 — 온라인 vs 오프라인 월매출#

① 서로 다른 두 집단(온라인/오프라인 채널)의 평균 매출 차이를 검정한다. Levene로 등분산부터 확인하고 t검정을 건다. (출처: cell[5], sales_1_ttest_indep.csv)

import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv(DATA_PATH + "sales_1_ttest_indep.csv", encoding="utf-8-sig")
online  = df[df["channel"] == "온라인"]["monthly_sales"]
offline = df[df["channel"] == "오프라인"]["monthly_sales"]
mean_on  = round(float(online.mean()), 3)
mean_off = round(float(offline.mean()), 3)
lev_stat, lev_p = stats.levene(online, offline)          # 등분산 검정
equal_var = lev_p >= 0.05                                 # p≥0.05면 등분산 가정
t_stat, p_val = stats.ttest_ind(online, offline, equal_var=equal_var)
decision = "기각" if round(float(p_val),3) < 0.05 else "채택"

③ 출력: 온라인 평균 3213.374, 오프라인 2849.041 / Levene p=0.05 → 등분산 True / t=4.786, p=0.0 → H₀ 기각 ④ stats.levene의 $H_0$는 “두 그룹 분산이 같다"이다. p≥0.05면 등분산으로 보고 ttest_ind(..., equal_var=True)(일반 t검정), p<0.05면 equal_var=False(Welch t검정)로 간다. 최종 p<0.05이므로 두 채널 평균 매출은 유의하게 다르다. ⑤ 💡 독립 t검정 = 등분산 검정 세트. ttest_ind를 바로 돌리지 말고 항상 levene으로 등분산을 먼저 본 뒤 equal_var를 정하는 게 정석이다.

02 · 대응표본 t검정 — 캠페인 전·후 전환율#

① 같은 대상의 두 측정값(캠페인 전/후 전환율)을 쌍으로 비교한다. “후 > 전"을 보려는 단측검정이다. (출처: cell[7], sales_2_ttest_paired.csv)

# 보완: df = pd.read_csv(DATA_PATH + "sales_2_ttest_paired.csv", encoding="utf-8-sig")
pre  = df["pre_cvr"]; post = df["post_cvr"]; diff = post - pre
t_stat, p_val = stats.ttest_rel(post, pre, alternative="greater")   # 대응 t검정(단측)

③ 출력: 전 평균 3.252%, 후 3.777%, 차이 0.526%p / t=13.235, p=0.0 → 기각(전환율 향상 효과 있음) ④ ttest_rel(post, pre)은 각 쌍의 차이 $D = post - pre$의 평균이 0인지 검정한다($H_0: \mu_D = 0$). alternative="greater"는 “후가 전보다 크다"는 단측 대립가설이다. ⑤ 💡 독립 t와 대응 t 구분. 서로 다른 사람들이면 독립(ttest_ind), 같은 사람의 전·후/좌·우 같은 짝이면 대응(ttest_rel)이다. 대응은 개인차가 상쇄돼 더 민감하게 차이를 잡아낸다.

03 · 일원 ANOVA + Tukey HSD — 직군별 토익#

① 3집단 이상(직군별) 평균 차이를 한 번에 검정하고, 유의하면 어느 쌍이 다른지 사후검정한다. (출처: cell[9], hr_3_anova.csv)

from statsmodels.stats.multicomp import pairwise_tukeyhsd
groups = df.groupby("job_type")["toeic_score"]
group_data = [g.values for _, g in groups]
f_stat, p_val = stats.f_oneway(*group_data)              # 일원 ANOVA
if round(float(p_val),3) < 0.05:
    tukey = pairwise_tukeyhsd(endog=df["toeic_score"], groups=df["job_type"], alpha=0.05)

③ 출력: 평균 IT직 854.8 / 마케팅직 820.975 / 기획직 794.875 / 영업직 782.925 / F=10.878, p=0.0 → 기각 / Tukey 유의 쌍: IT직 vs 기획직, IT직 vs 영업직, 마케팅직 vs 영업직 ④ stats.f_oneway는 그룹별 값 배열을 언패킹(*group_data)해 F 통계량을 낸다($H_0$: 모든 직군 평균 동일). 기각된 경우에만 pairwise_tukeyhsd로 쌍별 비교를 한다. ⑤ 💡 ANOVA는 “어딘가 다르다"까지만 말한다. 어느 그룹이 다른지는 알려주지 않으므로, 기각되면 Tukey HSD 사후검정으로 쌍을 찾아야 한다. 기각 안 되면 사후검정은 하지 않는다.

04 · 카이제곱 독립성 — 채용 전형 vs 합격 여부#

① 두 범주형 변수(전형 유형 × 합격 여부)가 서로 독립인지 검정한다. (출처: cell[11], hr_4_chisq.csv)

from scipy.stats import chi2_contingency
ct = pd.crosstab(df["hire_type"], df["final_pass"])      # 교차표(분할표)
chi2, p, dof, expected = chi2_contingency(ct)

③ 출력: chi2=46.137, dof=2, p=0.0 → 기각(전형 유형과 합격 여부에 유의한 연관성) ④ pd.crosstab으로 두 범주의 교차표를 만들고 chi2_contingency에 넣으면 카이제곱 통계량·p-value·자유도·기대도수를 돌려준다($H_0$: 두 변수 독립). p<0.05이므로 독립이 아니다(연관 있음). ⑤ 💡 기대도수 ≥ 5 조건. 카이제곱 독립성은 기대도수가 5 미만인 칸이 많으면 부정확해진다. 그럴 땐 Fisher’s Exact Test를 쓴다. dof=(행-1)×(열-1).

05 · 다중회귀 — 영업 사원 월매출 예측#

① 여러 독립변수로 연속형 종속변수(월매출)를 예측하고 유의변수·설명력을 본다. (출처: cell[13], sales_5_regression.csv)

import statsmodels.formula.api as smf
formula = "monthly_sales ~ call_count + visit_count + work_years + training_score"
model = smf.ols(formula=formula, data=df).fit()
params = model.params.drop("Intercept", errors="ignore")
max_var = params.idxmax()                                # 계수 최대 변수
pvals = model.pvalues.drop("Intercept", errors="ignore")
sig_count = int((pvals < 0.05).sum())                    # 유의변수 개수
r2 = round(float(model.rsquared), 3); adj_r2 = round(float(model.rsquared_adj), 3)

③ 출력: R²=0.940, Adj.R²=0.939, F=765.3 (개별 계수는 [출력 생략: model.summary() 표]) ④ smf.ols("Y ~ X1 + X2 + ...", data)는 R 스타일 수식으로 회귀식을 세운다. .fit() 후 .params(계수), .pvalues(유의성), .rsquared(설명력)를 뽑는다. 각 계수의 $H_0$는 “기울기=0"이다. ⑤ 💡 R² vs Adj.R². R²는 변수를 넣을수록 무조건 오르지만, Adj.R²는 쓸모없는 변수엔 페널티를 줘 과적합을 견제한다. 변수 개수가 다른 모델을 비교할 땐 Adj.R²를 본다.

06 · 로지스틱 회귀 — 서류 합격 예측#

① 이진(0/1) 결과(서류 합격 여부)의 발생 확률을 예측한다. (출처: cell[15], hr_6_logistic.csv)

from sklearn.metrics import accuracy_score
formula = "doc_pass ~ toeic_score + gpa + intern_count + cert_count"
model = smf.logit(formula=formula, data=df).fit(disp=False)
prob_pred = model.predict(df)                            # 예측 확률
y_pred = (prob_pred >= 0.5).astype(int)                  # 0.5 기준 이진 분류
acc = round(float(accuracy_score(df["doc_pass"], y_pred)), 3)

③ 출력: 계수 toeic 0.0041, gpa 1.4085(최대), intern 0.6128, cert 0.3361 / p-value 모두 <0.05(유의변수 4개) / Accuracy=0.848 ④ smf.logit은 로지스틱 회귀다. .predict는 0~1 사이 확률을 주므로, >= 0.5로 잘라 0/1 예측을 만든 뒤 accuracy_score로 실제와 맞춰본다. fit(disp=False)는 수렴 로그를 끈다. ⑤ 💡 로지스틱 계수는 로그오즈다. 계수 $\beta$를 $e^{\beta}$(오즈비)로 바꿔야 “1단위 증가 시 오즈가 몇 배” 로 해석된다. $\beta>0$이면 그 변수가 클수록 합격(1) 확률이 오른다.

07 · 종합문제 — ANOVA + 카이제곱 + 로지스틱(AUC)#

① 한 데이터에 세 검정을 순서대로 적용한다(기업유형별 토익 ANOVA + 인턴×합격 카이제곱 + 로지스틱 AUC). (출처: cell[17], hr_7_comprehensive1.csv)

from sklearn.metrics import accuracy_score, roc_auc_score
# (1) ANOVA
groups = df.groupby("company_type")["toeic_score"]
f_stat, f_p = stats.f_oneway(*[g.values for _, g in groups])
# (2) 카이제곱
ct2 = pd.crosstab(df["has_intern"], df["final_pass"])
chi2_stat, chi_p, dof, _ = chi2_contingency(ct2)
# (3) 로지스틱 + AUC
model3 = smf.logit("final_pass ~ age + gpa + toeic_score", data=df).fit(disp=False)
prob3 = model3.predict(df); y_pred3 = (prob3 >= 0.5).astype(int)
acc3 = round(float(accuracy_score(df["final_pass"], y_pred3)), 3)
auc3 = round(float(roc_auc_score(df["final_pass"], prob3)), 3)

③ 출력: 기업유형별 토익 평균 대기업 829.113 / 중견 789.933 / 스타트업 774.977 (F·chi2·Acc·AUC 수치는 [출력 생략: 실행 로그 하단]) ④ 세 검정을 한 흐름에서 쓴다 — ANOVA(3집단 평균), 카이제곱(범주형 독립성), 로지스틱(이진 예측). AUC는 roc_auc_score(실제, 예측확률)로, 정확도와 달리 0.5 임계값에 의존하지 않고 확률 순위를 평가한다. ⑤ 💡 Accuracy vs AUC. Accuracy는 0/1로 자른 뒤 맞은 비율이라 임계값(0.5)에 민감하고 불균형 데이터에 약하다. AUC는 예측 확률 자체의 변별력을 보므로 임계값과 무관하다 — 둘을 함께 보면 좋다.

① 문제1 — Anderson-Darling으로 일별 PM2.5의 정규성을 검정한다. (출처: 6_lecture.ipynb cell[4], 6_3_1.csv)

           .dropna().sort_values("date_only").reset_index(drop=True))

④ df.loc[조건, 컬럼목록]으로 행 조건 + 열 선택을 한 번에 한다. 복합 조건은 각 조건을 괄호로 묶고 &(and)/|(or)로 잇는다. df.loc[조건, "컬럼"] = 값은 조건에 맞는 행에만 값을 넣는 조건 할당이다. ⑤ 💡 파이썬의 and/or 대신 pandas는 &/|를 쓰고, 각 조건을 반드시 괄호로 감싼다(연산 우선순위 때문).

① 문제07 — 결측치 처리. (출처: cell[15])

missing = df[["Age", "Cabin", "Embarked"]].isna().sum()   # Age 177, Cabin 687, Embarked 2
df_filled = df.copy()
df_filled["Age"] = df_filled["Age"].fillna(df_filled["Age"].median())
df_filled["Embarked"] = df_filled["Embarked"].fillna(df_filled["Embarked"].mode()[0])

④ isna().sum()으로 컬럼별 결측 개수를 세고, 수치형 Age는 중앙값, 범주형 Embarked는 최빈값(mode()[0])으로 채운다. mode()는 Series를 반환하므로 [0]으로 첫 값을 뽑는다. ⑤ 💡 평균 대신 중앙값으로 채우면 이상치의 영향을 덜 받는다. Cabin(687개 결측)처럼 결측이 지나치게 많은 컬럼은 채우기보다 제거를 고려한다.

① 문제08~09 — 문자열 추출 / lambda apply. (출처: cell[17,19])

# 08 호칭 추출
df["Title"] = df["Name"].str.extract(r",\s*([^\.]+)\.").squeeze()
df["Title"].value_counts().head()   # Mr 517, Miss 182, Mrs 125, Master 40, Dr 7
# 09 AgeGroup
df["AgeGroup"] = df["Age"].apply(
    lambda x: "Unknown" if pd.isna(x)
    else "Child" if x < 18
    else "Adult" if x < 60
    else "Senior")   # Adult 575, Unknown 177, Child 113, Senior 26

④ str.extract(정규식)으로 이름에서 호칭(Mr/Miss…)을 뽑는다 — 정규식 ,\s*([^\.]+)\.는 “쉼표 뒤 ~ 마침표 앞” 부분을 잡는다. apply(lambda)는 각 나이를 구간 라벨로 바꾼다. ⑤ 💡 lambda 안의 연쇄 if/else는 위에서부터 순서대로 검사한다 — 결측(Unknown) → Child → Adult → Senior. pd.isna(x)를 맨 앞에 둬 결측을 먼저 걸러야 뒤의 비교에서 에러가 안 난다.

① 문제10 — numpy 벡터화. (출처: cell[21])

family_size = df["SibSp"].values + df["Parch"].values + 1
is_alone = family_size == 1
fare_level = np.where(df["Fare"].values >= 30, "High", "Low")
alone_high_count = np.sum(is_alone & (fare_level == "High"))   # 79

③ 출력: 혼자이면서 고요금인 승객 = 79명 ④ .values로 numpy 배열을 꺼내 반복문 없이 한 번에 계산한다. family_size=형제/배우자(SibSp)+부모/자녀(Parch)+본인 1. np.where(조건, 참값, 거짓값)은 조건별 라벨을, np.sum(불리언)은 True 개수를 센다. ⑤ 💡 벡터화가 빠른 이유. for 루프로 한 행씩 도는 대신, numpy가 배열 전체를 C 레벨에서 한 번에 처리한다 — 큰 데이터에서 수십~수백 배 빠르다.
