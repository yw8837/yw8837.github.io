이어드림스쿨 AI 과정 파이썬 첫 시간 정리입니다. 자료형·변수·연산자·조건문·리스트 — 파이썬의 기본 뼈대를, 코딩이 처음인 분도 이해하도록 풀어 썼습니다. 🐍

📖 수업 내용#

01 · 자료형 (Data Type)#

컴퓨터는 숫자와 문자를 다르게 취급합니다. 3이라는 숫자와 "3"이라는 문자는 완전히 다른 것이에요. 파이썬 기본 자료형 5가지부터 알아봅니다.

정수 int · 실수 float#

age = 25          # int — 소수점 없는 숫자
temperature = -5
height = 175.5    # float — 소수점 있는 숫자
pi = 3.14159

문자열 str#

따옴표(" 또는 ')로 감싼 텍스트입니다. 숫자처럼 생겼어도 따옴표 안에 있으면 문자열입니다.

name = "홍길동"
phone = "010-1234-5678"   # 숫자처럼 보이지만 문자열!

리스트 list · 불리언 bool#

fruits = ["사과", "바나나", "체리"]   # 여러 값을 순서대로 담는 바구니 []
mixed = [1, "홍길동", True, 3.14]      # 다양한 자료형을 섞어도 OK

is_student = True    # bool — True(참) / False(거짓) 두 가지만

자료형 확인 — type()#

print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("안녕"))    # <class 'str'>
print(type([1,2,3]))   # <class 'list'>
print(type(True))      # <class 'bool'>

02 · 변수 (Variable) — 값에 이름표 붙이기#

변수는 데이터를 담는 이름 붙은 상자입니다. =는 “같다"가 아니라 “오른쪽 값을 왼쪽 이름에 넣는다” 는 뜻입니다.

name = "홍길동"    # "홍길동"을 name에 저장
age = 25
print(name)        # 홍길동
규칙 예시
영문자·숫자·_만 사용 user_name, score1
숫자로 시작 불가 ❌ 1score → ✅ score1
공백 불가 ❌ my name → ✅ my_name
예약어 사용 불가 ❌ if, for, True
관례: 스네이크 표기법 student_name, total_score

💡 스네이크 표기법(snake_case): 단어 사이를 _로 연결. 파이썬 공식 표준 스타일(PEP 8)입니다.

03 · 연산자 (Operator)#

기본 사칙연산#

a, b = 10, 3
print(a + b)    # 13
print(a - b)    # 7
print(a * b)    # 30
print(a / b)    # 3.3333...  나누기는 항상 실수 반환

자주 쓰는 특수 연산자#

연산자 이름 예시 결과
// 몫 (정수 나눗셈) 10 // 3 3
% 나머지 10 % 3 1
** 거듭제곱 2 ** 8 256

💡 % 꿀팁 — 홀짝 판별: 2로 나눈 나머지가 0이면 짝수, 1이면 홀수.

문자열 연산#

print("안녕" + "하세요")    # 안녕하세요   (+ 이어 붙이기)
print("파이썬" * 3)         # 파이썬파이썬파이썬   (* 반복)

⚠️ 숫자 + 문자열은 에러! 1 + "살" → TypeError. 숫자를 str()로 먼저 변환해야 합니다.

04 · 형 변환 (Type Casting)#

input() 으로 받은 값은 무조건 문자열입니다. 계산하려면 변환이 필요합니다.

user_input = input("숫자: ")   # "100" (문자열!)
number = int(user_input)        # 정수로 변환
print(number + 50)              # 150
함수 변환 예시 → 결과
int() → 정수 int("42") → 42
float() → 실수 float("3.14") → 3.14
str() → 문자열 str(100) → "100"
list() → 리스트 list("abc") → ['a','b','c']

⚠️ int("3.14")는 에러! 소수점 문자열은 int(float("3.14")) 처럼 float을 거쳐야 합니다.

05 · 인덱싱·슬라이싱#

순서를 0부터 셉니다. [번호]로 한 개, [시작:끝]으로 범위를 꺼냅니다(끝은 미포함).

word = "Python"
        P  y  t  h  o  n
인덱스: 0  1  2  3  4  5
음수:  -6 -5 -4 -3 -2 -1

word = "Python"
print(word[0])     # P   첫 번째
print(word[-1])    # n   마지막

beta = "abcdefg"
print(beta[2:5])   # cde   인덱스 2,3,4 (5 미포함)
print(beta[:3])    # abc   처음부터
print(beta[4:])    # efg   끝까지

💡 리스트도 똑같습니다: [90, 85, 78, 92][1:3] → [85, 78].

06 · 조건문 (Conditional) — “만약 ~ 라면”#

비교 연산자 · 논리 연산자#

연산자 의미 연산자 의미
== 같다 and 양쪽 모두 참이면 참
!= 다르다 or 하나라도 참이면 참
> < >= <= 크기 비교 not 참/거짓 반전

⚠️ =(하나)는 대입, ==(둘)은 비교. 가장 헷갈리는 부분!

if - elif - else#

score = int(input("점수: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"학점: {grade}")

💡 들여쓰기가 핵심! 파이썬은 들여쓰기(스페이스 4칸)로 코드 블록을 구분합니다. 어긋나면 IndentationError. 💡 f-string: f"학점: {grade}" 처럼 f"..." 안 { }에 변수를 넣습니다.

07 · 리스트 (List)#

여러 값을 순서 있게 담고, 추가·삭제·수정이 자유로운 자료구조입니다.

fruits = ["사과", "바나나", "체리"]
print(fruits[0])     # 사과
fruits[1] = "포도"   # 값 수정
print(len(fruits))   # 3 (길이)
메서드 역할
.append(값) 끝에 추가
.insert(위치, 값) 원하는 위치에 삽입
.remove(값) 해당 값 첫 번째 삭제
.sort() / .sort(reverse=True) 오름차순 / 내림차순 정렬 
cart = ["라면", "계란", "우유"]
cart.append("빵")        # ['라면','계란','우유','빵']
cart.insert(0, "쌀")     # ['쌀','라면','계란','우유','빵']
cart.remove("계란")      # ['쌀','라면','우유','빵']

💡 중첩 리스트: info = ["홍길동", 20, ["파이썬","자바"]] → info[2][0] = "파이썬".

08 · 시퀀스 자료형의 공통 특징#

str과 list는 둘 다 순서가 있는 시퀀스라 공통 기능을 씁니다.

기능 사용법 str list
포함 여부 값 in 변수 "파" in "파이썬" → True 3 in [1,2,3] → True
길이 len() len("Hello") → 5 len([1,2,3]) → 3
이어 붙이기 + "a"+"b" [1]+[2]
반복 * "Ha"*3 [0]*3

차이점: str은 불변(값 변경 ❌), list는 가변(값 변경 ✅).

text = "hello"
text[0] = "H"      # TypeError (str은 불변)

items = ["a", "b"]
items[0] = "A"     # OK (list는 가변)

📚 참고자료#

수업 내용에 더해, 알아두면 좋은 내용을 Python 공식 문서에서 보충했습니다.

f-string 포매팅 — 숫자를 예쁘게#

f"{값:서식}" 형태로 소수점 자리·정렬·천 단위 콤마를 지정할 수 있습니다.

pi = 3.14159
print(f"{pi:.2f}")        # 3.14      소수점 2자리
print(f"{1234567:,}")     # 1,234,567 천 단위 콤마
print(f"{'이름':>10}")     # 오른쪽 정렬 10칸

출처: 형식 명세 미니 언어

Truthy / Falsy — “비어 있으면 거짓”#

if 조건에서 거짓(False)으로 취급되는 값들이 있습니다: None, False, 0, 0.0, ""(빈 문자열), [](빈 리스트), {}(빈 딕셔너리). 나머지는 모두 참.

items = []
if not items:          # 빈 리스트는 False → 실행됨
    print("목록이 비어있음")

== vs is, 그리고 None#

==는 값이 같은지, is는 같은 객체인지 비교합니다. “값이 없음"을 뜻하는 None은 is로 체크하는 것이 관례입니다.

result = None
if result is None:     # None 체크는 == 대신 is 권장
    print("결과 없음")

리스트 컴프리헨션 (맛보기)#

반복문(다음 시간 학습)과 조건을 한 줄로 압축해 리스트를 만드는 파이썬다운 문법입니다.

squares = [x**2 for x in range(1, 6)]   # [1, 4, 9, 16, 25]
evens = [x for x in range(10) if x % 2 == 0]   # [0,2,4,6,8]

다음에 배울 자료형 미리보기#

  • 튜플 (1, 2, 3) — 값을 바꿀 수 없는 리스트(불변)
  • 딕셔너리 {"키": "값"} — 이름표로 값을 찾는 자료형
  • 집합 {1, 2, 3} — 중복 없는 모음

마무리#

자료형을 이해하면 데이터를 어떻게 다룰지 보이고, 조건문을 알면 프로그램이 상황에 따라 다르게 동작하며, 리스트는 곧 배울 반복문(for)과 만나 진짜 강력해진다.

처음부터 완벽히 외우려 하지 말고, 직접 손으로 쳐보면서 “아, 이렇게 동작하는구나"를 느끼는 게 가장 중요합니다. 💪
