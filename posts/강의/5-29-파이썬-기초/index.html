파이썬은 문법이 영어 문장처럼 읽히는 언어입니다. 코딩을 한 번도 해본 적 없어도 “내가 컴퓨터에게 이렇게 말하면 컴퓨터가 이렇게 이해하는구나” 라는 감각만 잡으면 빠르게 익힐 수 있습니다. 오늘 배운 내용을 최대한 쉬운 말로 풀어 정리해 봤습니다. 🐍

1. 자료형 (Data Type) — 데이터의 종류#

컴퓨터는 숫자와 문자를 다르게 취급합니다. 3이라는 숫자와 "3"이라는 문자는 완전히 다른 것이에요. 파이썬에서 다루는 기본 자료형 5가지를 먼저 알아봅시다.

정수 int (Integer)#

소수점 없는 숫자입니다.

age = 25
score = 100
temperature = -5

실수 float (Floating point)#

소수점이 있는 숫자입니다.

height = 175.5
pi = 3.14159
weight = -0.5

문자열 str (String)#

따옴표(" 또는 ')로 감싼 텍스트입니다. 숫자처럼 생겼어도 따옴표 안에 있으면 문자열입니다.

name = "홍길동"
phone = "010-1234-5678"   # 숫자처럼 보이지만 문자열!
greeting = '안녕하세요'

리스트 list#

여러 값을 순서대로 담는 바구니입니다. 대괄호 []로 만듭니다.

fruits = ["사과", "바나나", "체리"]
scores = [95, 87, 72, 100]
mixed = [1, "홍길동", True, 3.14]   # 다양한 자료형을 섞어도 됩니다

불리언 bool (Boolean)#

True(참) 또는 False(거짓), 딱 두 가지 값만 가집니다. 조건을 판단할 때 사용합니다.

is_student = True
is_adult = False

자료형 확인 — type()#

어떤 값의 자료형이 궁금할 때는 type() 함수를 씁니다.

print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("안녕"))    # <class 'str'>
print(type([1,2,3]))   # <class 'list'>
print(type(True))      # <class 'bool'>

2. 변수 (Variable) — 값에 이름표 붙이기#

변수는 데이터를 담는 이름 붙은 상자입니다. = 기호는 “같다"가 아니라 “오른쪽 값을 왼쪽 이름에 넣는다” 는 뜻입니다.

name = "홍길동"    # "홍길동"을 name에 저장
age = 25           # 25를 age에 저장
print(name)        # 홍길동
print(age)         # 25

변수 이름 규칙#

규칙 예시
영문자·숫자·_(언더스코어)만 사용 user_name, score1
숫자로 시작 불가 ❌ 1score → ✅ score1
공백 불가 (공백 대신 _ 사용) ❌ my name → ✅ my_name
파이썬 예약어 사용 불가 ❌ if, for, True
파이썬 관례: 스네이크 표기법 student_name, total_score

💡 스네이크 표기법(snake_case): 단어 사이를 _로 연결합니다. 파이썬의 공식 표준 스타일(PEP 8)입니다.
자바스크립트에서 쓰는 camelCase(첫 단어 소문자, 이후 단어 대문자)와는 다릅니다.

3. 연산자 (Operator)#

기본 사칙연산#

a = 10
b = 3

print(a + b)    # 13  (더하기)
print(a - b)    # 7   (빼기)
print(a * b)    # 30  (곱하기)
print(a / b)    # 3.3333...  (나누기 — 항상 실수 반환)

파이썬에서 자주 쓰는 특수 연산자#

연산자 이름 의미 예시 결과
// 몫 (정수 나눗셈) 나눈 후 소수점 버림 10 // 3 3
% 나머지 나눈 후 남은 나머지 10 % 3 1
** 거듭제곱 제곱, 세제곱 등 2 ** 10 1024 
print(10 // 3)   # 3   (3.33... 에서 소수점 버림)
print(10 % 3)    # 1   (10 = 3×3 + 1, 나머지 1)
print(2 ** 8)    # 256 (2의 8승)

💡 % 활용 꿀팁 — 홀짝 판별
어떤 수를 2로 나눈 나머지가 0이면 짝수, 1이면 홀수입니다.

num = 7
print(num % 2)   # 1 → 홀수!

4. 문자열 연산 — 문자도 더하고 곱할 수 있다?#

파이썬에서 문자열은 +로 이어 붙이고, *로 반복할 수 있습니다.

first = "안녕"
second = "하세요"
print(first + second)    # 안녕하세요

word = "파이썬"
print(word * 3)          # 파이썬파이썬파이썬

⚠️ 숫자 + 문자열은 에러!
1 + "살" 처럼 서로 다른 자료형을 +로 합치면 TypeError가 납니다.
숫자를 먼저 str()로 변환해야 합니다.

age = 25
print(str(age) + "살")   # 25살  ✅
print(age + "살")         # TypeError ❌

5. 형 변환 (Type Casting) — 자료형 바꾸기#

input() 함수로 받은 값은 무조건 문자열입니다. 숫자 계산을 하려면 변환이 필요합니다.

user_input = input("숫자를 입력하세요: ")   # "100" (문자열!)
print(type(user_input))                      # <class 'str'>

number = int(user_input)                     # 정수로 변환
print(number + 50)                           # 150
함수 변환 방향 예시 결과
int() → 정수 int("42"), int(3.9) 42, 3
float() → 실수 float("3.14"), float(7) 3.14, 7.0
str() → 문자열 str(100), str(True) "100", "True"
list() → 리스트 list("abc") ['a','b','c']

⚠️ 주의: int("3.14")는 에러납니다! 소수점 있는 문자열은 float() 먼저, 그 다음 int()로 변환하세요.

int(float("3.14"))   # 3  ✅

6. 인덱싱과 슬라이싱 — 문자열·리스트에서 원하는 부분 꺼내기#

인덱싱 (Indexing) — 한 글자 꺼내기#

파이썬은 순서를 0부터 셉니다. [번호]로 원하는 위치의 값을 꺼냅니다.

word = "Python"
         P  y  t  h  o  n
인덱스:  0  1  2  3  4  5
음수:   -6 -5 -4 -3 -2 -1

word = "Python"
print(word[0])    # P   (첫 번째)
print(word[2])    # t   (세 번째)
print(word[-1])   # n   (마지막)
print(word[-2])   # o   (뒤에서 두 번째)

💡 음수 인덱스: -1은 맨 마지막, -2는 뒤에서 두 번째입니다. 긴 리스트에서 마지막 요소를 꺼낼 때 편리합니다.

슬라이싱 (Slicing) — 범위 잘라내기#

[시작:끝] 형식으로 씁니다. 끝 번호는 포함하지 않습니다.

beta = "abcdefg"

print(beta[2:5])   # cde   (인덱스 2,3,4 — 5는 미포함)
print(beta[:3])    # abc   (처음부터 인덱스 2까지)
print(beta[4:])    # efg   (인덱스 4부터 끝까지)
print(beta[:])     # abcdefg (전체 복사)

💡 리스트에서도 똑같이 동작합니다.

scores = [90, 85, 78, 92, 88]
print(scores[1:4])   # [85, 78, 92]
print(scores[:2])    # [90, 85]

7. 조건문 (Conditional) — “만약 ~ 라면”#

조건문은 “조건이 참이면 A를 실행하고, 거짓이면 B를 실행해” 라는 분기점입니다.

비교 연산자#

먼저 조건을 표현하는 비교 연산자를 알아야 합니다.

연산자 의미 예시 결과
== 같다 5 == 5 True
!= 같지 않다 5 != 3 True
> 크다 10 > 5 True
< 작다 3 < 1 False
>= 크거나 같다 5 >= 5 True
<= 작거나 같다 3 <= 2 False

⚠️ =(하나)는 대입, ==(둘)은 비교입니다. 헷갈리기 쉬운 부분!

논리 연산자#

연산자 의미 참이 되는 조건
and 그리고 (AND) 양쪽 모두 True일 때만 True
or 또는 (OR) 하나라도 True이면 True
not 부정 (NOT) True → False, False → True 
age = 20
print(age >= 18 and age < 65)   # True  (성인 근로자)
print(age < 10 or age > 60)     # False (어린이도 노인도 아님)
print(not True)                  # False

if - else 기본 구조#

score = 75

if score >= 60:
    print("합격")        # score가 60 이상이면 실행
else:
    print("불합격")      # 그렇지 않으면 실행

💡 들여쓰기(indentation)가 핵심! 파이썬은 들여쓰기로 코드 블록을 구분합니다. 스페이스 4칸 또는 Tab 1번을 사용합니다. 들여쓰기가 맞지 않으면 IndentationError가 납니다.

if - elif - else 다중 조건#

조건이 세 가지 이상일 때는 elif(else if의 약자)를 씁니다.

score = int(input("점수 입력: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"학점: {grade}")

💡 f-string: f"텍스트 {변수명}" 형태로 문자열 안에 변수값을 쉽게 넣을 수 있습니다. "학점: " + grade 보다 훨씬 깔끔합니다.

8. 리스트 (List) — 여러 값을 한 바구니에#

리스트는 여러 값을 순서 있게 담는 자료구조입니다. 값을 추가·삭제·수정할 수 있어 매우 유연합니다.

기본 사용법#

# 리스트 만들기
fruits = ["사과", "바나나", "체리", "딸기"]

# 인덱싱으로 꺼내기
print(fruits[0])    # 사과
print(fruits[-1])   # 딸기

# 값 수정
fruits[1] = "포도"
print(fruits)       # ['사과', '포도', '체리', '딸기']

# 길이 확인
print(len(fruits))  # 4

자주 쓰는 리스트 메서드#

메서드 역할 예시
.append(값) 끝에 값 추가 fruits.append("망고")
.insert(위치, 값) 원하는 위치에 삽입 fruits.insert(1, "키위")
.remove(값) 첫 번째로 나오는 해당 값 삭제 fruits.remove("사과")
.sort() 오름차순 정렬 numbers.sort()
.sort(reverse=True) 내림차순 정렬 numbers.sort(reverse=True) 
cart = ["라면", "계란", "우유"]

cart.append("빵")           # 끝에 추가
print(cart)                  # ['라면', '계란', '우유', '빵']

cart.insert(0, "쌀")        # 맨 앞에 삽입
print(cart)                  # ['쌀', '라면', '계란', '우유', '빵']

cart.remove("계란")         # 계란 삭제
print(cart)                  # ['쌀', '라면', '우유', '빵']

중첩 리스트 (2차원 리스트)#

리스트 안에 리스트를 넣을 수 있습니다. 표(행과 열) 구조를 만들 때 활용됩니다.

student_info = ["홍길동", 20, "컴퓨터공학", ["파이썬", "자바"]]

print(student_info[0])      # 홍길동
print(student_info[3])      # ['파이썬', '자바']
print(student_info[3][0])   # 파이썬  (중첩 리스트 접근)

9. 시퀀스 자료형의 공통 특징#

str(문자열)과 list(리스트)는 모두 시퀀스(Sequence) 자료형입니다. 순서가 있기 때문에 공통으로 사용할 수 있는 기능이 있습니다.

기능 사용법 str 예시 list 예시
포함 여부 확인 값 in 변수 "파" in "파이썬" → True 3 in [1,2,3] → True
미포함 확인 값 not in 변수 "z" not in "Python" → True 5 not in [1,2] → True
길이 확인 len(변수) len("Hello") → 5 len([1,2,3]) → 3
이어 붙이기 + "Hello" + " World" [1,2] + [3,4] → [1,2,3,4]
반복 * "Ha" * 3 → "HaHaHa" [0] * 3 → [0,0,0]

str과 list의 차이점#

구분 str list
값 변경 ❌ 불가 (불변, immutable) ✅ 가능 (가변, mutable)
.append() ❌ AttributeError ✅ 사용 가능
.split() ✅ 사용 가능 ❌ AttributeError 
# str은 값을 변경할 수 없습니다
text = "hello"
text[0] = "H"      # TypeError: 'str' object does not support item assignment

# list는 변경 가능합니다
items = ["a", "b", "c"]
items[0] = "A"     # OK!
print(items)        # ['A', 'b', 'c']

마무리#

오늘 배운 개념들은 파이썬의 뼈대에 해당합니다. 자료형을 이해하면 데이터를 어떻게 다뤄야 할지 보이고, 조건문을 알면 프로그램이 상황에 따라 다르게 동작하게 만들 수 있습니다. 리스트는 앞으로 반복문(for)과 결합해서 훨씬 강력하게 활용됩니다.

처음부터 완벽히 외우려 하지 말고, 직접 손으로 쳐보면서 “아, 이렇게 동작하는구나"를 느끼는 것이 가장 중요합니다. 💪
