이어드림스쿨 AI 과정 파이썬 두 번째 시간 정리입니다. 지난 시간(자료형·조건문·리스트) 위에 — 튜플·딕셔너리로 묶고, 반복문(for·while)으로 처리하고, 함수로 재사용하는 도구를 더합니다. 🐍

📖 수업 내용#

01 · 문자열·리스트 메서드#

pop() — 꺼내면서 삭제#

my_list = [2, 3, 5, 7, 11]
print(my_list.pop(0))   # 2    인덱스 0을 꺼내고 삭제
print(my_list.pop())    # 11   괄호 비우면 마지막
print(my_list)          # [3, 5, 7]

💡 remove는 지우기만, pop은 지우면서 그 값을 돌려줍니다.

count · split · join#

"elice and alice".count("e")   # 3   특정 값 개수

"1 2 3".split()         # ['1','2','3']   문자열 → 리스트 (공백 기준)
"Na,Mg,Al".split(",")   # ['Na','Mg','Al']

"".join(["e","l","i","c","e"])   # "elice"        리스트 → 문자열
"→".join(["서울","대전","대구"]) # "서울→대전→대구"

💡 split ↔ join은 한 쌍 (쪼개기 ↔ 합치기). join은 "구분자".join(리스트) 순서 주의.

02 · 튜플 (Tuple) — 바뀌지 않는 묶음#

리스트와 거의 같지만 한 번 만들면 값을 못 바꾸는(불변) 자료형. 소괄호 ()로 만듭니다.

t = (1, 2, 3, 4, 5)
print(t[2])       # 3        인덱싱·슬라이싱·in·len·+·* 가능
print(2 in t)     # True
t[0] = 99         # TypeError — 수정 불가

⚠️ 원소 1개 튜플은 쉼표 필수: (1,)은 튜플, (1)은 그냥 정수.

언제 쓰나? 좌표·날짜처럼 바뀌면 안 되는 데이터, 딕셔너리 Key, 함수가 여러 값을 반환할 때.

자료형 표현 수정
리스트 [1, 2, 3] 가능
튜플 (1, 2, 3) 불가(안전)

03 · 딕셔너리 (Dictionary) — 이름표가 붙은 데이터#

키(key)와 값(value)을 짝지어 저장. 번호가 아니라 이름(키) 으로 값을 꺼냅니다. 중괄호 {}.

person = {"name": "Rabbit", "age": 22}
print(person["name"])               # Rabbit (키로 접근)

person["mail"] = "rabbit@elice.com" # 추가
person["age"] = 23                  # 수정 (추가와 문법 동일)
del person["age"]                   # 삭제

person.keys()    # 키 전체
person.values()  # 값 전체
person.items()   # (키, 값) 쌍 전체

⚠️ 키 규칙: 바뀌지 않는 자료형만 가능 (문자열·숫자·튜플 OK / 리스트 ❌).

# for문과 조합 (가장 많이 쓰는 패턴)
scores = {"수학": 95, "영어": 88}
for 과목, 점수 in scores.items():
    print(f"{과목}: {점수}점")

💡 웹에서 데이터를 주고받는 JSON이 딕셔너리와 똑같이 생겼습니다. 앞으로 API 다룰 때 매일 만납니다.

04 · 반복문 (Loop)#

for 문 · range()#

for fruit in ["사과", "바나나"]:   # 목록을 하나씩 꺼내 반복
    print(fruit)

for i in range(1, 10):             # 1~9 (끝 미포함)
    print(f"3 x {i} = {3 * i}")    # 구구단 3단

⚠️ range(1, 10)은 10 직전까지. 끝 숫자는 포함하지 않습니다(슬라이싱과 같은 규칙).

while 문 · break#

i = 5
while i > 0:        # 조건이 참인 동안 반복
    print(i)
    i -= 1          # 이 줄이 없으면 무한루프!
print("발사!")

for fruit in ["사과", "망고", "딸기"]:
    if fruit == "망고":
        break       # 망고를 만나면 반복 종료
    print(fruit)

💡 for → 횟수·범위가 정해질 때 / while → 조건으로 끝날 때. 무한루프 시 Ctrl + C.

05 · 함수와 메서드#

함수는 작업하는 코드 묶음에 이름을 붙여 재사용하는 것. 기본 틀은 입력 → 처리 → 출력.

내장 함수 · 사용자 정의 함수#

len([1,2,3])     # 3
sum([1,2,3])     # 6
max([1,2,3])     # 3

def plus_double(a, b):     # def 이름(매개변수):
    c = a + b
    return 2 * c           # return으로 결과 반환

print(plus_double(3, 4))   # 14

⚠️ return이 없으면 결과는 None. 화면에 print만 하는 것과, 값을 return해 다른 곳에 쓰는 것은 다릅니다.

전역 변수 vs 지역 변수#

x = "전역"          # 어디서든 접근

def my_func():
    y = "지역"      # 이 함수 안에서만 존재
    print(x)        # 전역변수 읽기 OK

my_func()
print(y)            # NameError! — 함수 밖엔 y 없음

함수 vs 메서드#

구분 함수 메서드
호출 함수명(자료) 자료.메서드명()
예시 len(my_list) my_list.append(4)

📚 참고자료#

수업 마지막에 다룬 실무 관행 + 알아두면 좋은 내용을 Python 공식 문서에서 보충했습니다.

타입 힌트 (Type Hint)#

매개변수·반환값의 자료형을 명시합니다. 강제는 아니지만(어겨도 에러 안 남) 가독성·협업에 도움이 됩니다.

def add(a: int, b: int) -> int:   # int 둘을 받아 int 반환
    return a + b

def log(msg: str) -> None:        # 반환값 없으면 -> None
    print(msg)

출처: typing — 형 힌트 지원

독스트링 (Docstring)#

함수 첫 줄에 """설명"""을 적으면 함수의 설명서가 됩니다. help(함수명)으로 보고, 라이브러리 공식 문서도 대부분 여기서 자동 생성됩니다.

def c_to_f(c: float) -> float:
    """섭씨를 화씨로 변환한다."""
    return c * 9 / 5 + 32

help(c_to_f)   # 위 설명이 출력됨

반복을 더 편하게 — enumerate · zip#

# enumerate: 인덱스와 값을 동시에
for i, fruit in enumerate(["사과", "배"]):
    print(i, fruit)        # 0 사과 / 1 배

# zip: 두 리스트를 나란히 묶기
names, ages = ["철수", "영희"], [20, 22]
for name, age in zip(names, ages):
    print(name, age)       # 철수 20 / 영희 22

dict(zip(names, ages))     # {'철수': 20, '영희': 22}

break 의 짝 — continue#

break는 반복을 완전히 탈출, continue는 이번 회차만 건너뛰고 다음으로 진행합니다.

for i in range(1, 6):
    if i == 3:
        continue       # 3만 건너뜀
    print(i)           # 1 2 4 5

마무리#

데이터를 묶고(튜플·딕셔너리) → 반복으로 처리하고(for·while) → 함수로 포장해 재사용한다. 이 셋이 합쳐지면 “성적표 분석·재고 계산·로그인 처리” 같은 진짜 프로그램이 된다.
