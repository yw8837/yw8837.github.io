지난 시간에 자료형·변수·조건문·리스트를 배웠습니다. 오늘은 그 위에 “여러 데이터를 묶고(튜플·딕셔너리), 반복하고(for·while), 묶음으로 재사용(함수)” 하는 도구를 얹습니다. 여기까지 오면 비로소 “프로그램다운 프로그램"을 만들 수 있습니다. 🐍

1. 문자열·리스트 추가 메서드#

리스트와 문자열을 더 자유롭게 다루는 메서드 4개를 먼저 익힙니다.

pop() — 꺼내면서 삭제#

값을 삭제하는 동시에 그 값을 돌려줍니다. (remove는 돌려주지 않습니다.)

my_list = [2, 3, 5, 7, 11]

print(my_list.pop(0))   # 2    (인덱스 0을 꺼내고 삭제)
print(my_list.pop())    # 11   (괄호 비우면 맨 마지막)
print(my_list)          # [3, 5, 7]

count() — 개수 세기#

[2, 2, 3, 2].count(2)          # 3
"elice and alice".count("e")   # 3

split() — 문자열을 리스트로 쪼개기#

"1 2 3".split()         # ['1', '2', '3']   (괄호 비우면 공백 기준)
"Na,Mg,Al".split(",")   # ['Na', 'Mg', 'Al']

join() — 리스트를 문자열로 합치기#

split()의 반대입니다. 구분자.join(리스트) 순서가 헷갈리기 쉬우니 주의하세요.

"".join(["e", "l", "i", "c", "e"])    # "elice"
"→".join(["서울", "대전", "대구"])     # "서울→대전→대구"

💡 split()과 join()은 한 쌍입니다. “문자열 → 쪼개서 가공 → 다시 합치기"는 데이터 처리에서 가장 많이 쓰는 흐름입니다.

2. 튜플 (Tuple) — 바뀌지 않는 묶음#

튜플은 리스트와 거의 같지만 한 번 만들면 값을 바꿀 수 없습니다(불변). 소괄호 ()로 만듭니다.

t = (1, 2, 3, 4, 5)

# 리스트처럼 되는 것들
print(t[2])       # 3        (인덱싱)
print(t[:2])      # (1, 2)   (슬라이싱)
print(2 in t)     # True     (포함 여부)
print(len(t))     # 5        (길이)

# 리스트와 다른 점 — 수정 불가
t[0] = 99         # TypeError: 'tuple' object does not support item assignment

⚠️ 원소가 1개인 튜플은 쉼표 필수!

(1,)    # 튜플 ✅
(1)     # 그냥 정수 1 ❌ (괄호일 뿐)

언제 쓰나? 좌표·날짜처럼 바뀌면 안 되는 데이터, 딕셔너리의 키, 함수가 여러 값을 한 번에 돌려줄 때 사용합니다.

자료형 표현 수정 특징
리스트 List [1, 2, 3] 가능 순서 O, 자유롭게 변경
튜플 Tuple (1, 2, 3) 불가 순서 O, 불변(안전)

3. 딕셔너리 (Dictionary) — 이름표가 붙은 데이터#

딕셔너리는 키(key)와 값(value)을 짝지어 저장합니다. 사전에서 단어(키)를 찾으면 뜻(값)이 나오는 것과 같습니다. 중괄호 {}로 만듭니다.

person = {"name": "Rabbit", "age": 22}

# 값 꺼내기 — 번호가 아니라 '키'로 접근
print(person["name"])    # Rabbit

추가·수정·삭제 (CRUD)#

person["mail"] = "rabbit@elice.com"   # 추가 (없는 키에 넣으면 새로 생김)
person["age"] = 23                    # 수정 (있는 키에 넣으면 덮어씀)
del person["age"]                     # 삭제

키·값·쌍 꺼내기#

person.keys()      # 키 전체
person.values()    # 값 전체
person.items()     # (키, 값) 쌍 전체

⚠️ 키 규칙: 키에는 바뀌지 않는 자료형만 쓸 수 있습니다. 문자열·숫자·튜플 → OK, 리스트 → ❌ TypeError.

for문과 조합 (자주 쓰는 패턴)#

scores = {"수학": 95, "영어": 88, "과학": 92}

for 과목, 점수 in scores.items():
    print(f"{과목}: {점수}점")

💡 웹에서 데이터를 주고받는 JSON 형식이 딕셔너리와 똑같이 생겼습니다. 앞으로 API를 다룰 때 매일 만나게 됩니다.

4. 반복문 (Loop) — 같은 일을 자동으로 되풀이#

별 5개를 출력하려고 print를 5번 쓸 수는 있지만, 100개라면? 반복문이 답입니다.

for 문 — 목록을 하나씩 꺼내기#

for fruit in ["사과", "바나나", "체리"]:
    print(fruit)
# 사과 / 바나나 / 체리 (한 줄씩)

for + range() — 정해진 횟수만큼#

range()는 연속된 숫자를 만들어 줍니다. 끝 숫자는 포함하지 않습니다.

range(5)         # 0, 1, 2, 3, 4
range(1, 6)      # 1, 2, 3, 4, 5
range(0, 10, 2)  # 0, 2, 4, 6, 8  (2칸씩)

for i in range(1, 10):
    print(f"3 x {i} = {3 * i}")   # 구구단 3단

while 문 — 조건이 참인 동안 계속#

i = 5
while i > 0:
    print(i)     # 5 4 3 2 1
    i -= 1       # 이 줄이 없으면 무한루프!
print("발사!")

⚠️ 무한루프 주의: while 안에서 조건을 변하게 만드는 코드(i -= 1 등)를 꼭 넣어야 합니다. 멈추지 않으면 Ctrl + C로 강제 종료하세요.

break — 반복 도중 탈출#

for fruit in ["사과", "바나나", "체리", "망고", "딸기"]:
    if fruit == "망고":
        break        # 망고를 만나면 반복 종료
    print(fruit)
# 사과 / 바나나 / 체리

💡 for vs while 언제? 횟수·범위가 정해져 있으면 for, 조건에 따라 끝나면 while을 주로 씁니다.

구문 용도
for i in 시퀀스 리스트·문자열 원소 순회
for i in range(n) n번 반복
while 조건 조건이 참인 동안 반복
break 반복문 즉시 탈출

5. 함수 (Function) — 코드 묶어서 재사용하기#

함수는 특정 작업을 하는 코드 묶음에 이름을 붙여 두고 필요할 때마다 부르는 것입니다. 프로그래밍의 기본 틀은 입력 → 처리 → 출력입니다.

내장 함수 — 파이썬이 미리 만들어 둔 것#

len([1, 2, 3])        # 3   (길이)
sum([1, 2, 3, 4, 5])  # 15  (합)
max([1, 2, 3])        # 3   (최댓값)
min([1, 2, 3])        # 1   (최솟값)

직접 함수 만들기 — def#

def plus_double(a, b):     # def 이름(매개변수):
    c = a + b              #   들여쓰기로 본문
    return 2 * c           #   return으로 결과 돌려주기

print(plus_double(3, 4))   # 14   ( (3+4) × 2 )
  • 매개변수(parameter): 함수가 받는 입력값 자리 (a, b)
  • return: 결과를 함수 밖으로 돌려줌

⚠️ return이 없으면 결과는 None! 화면에 print만 하는 것과, 값을 return해서 다른 곳에 쓰는 것은 다릅니다.

def add(a, b):
    print(a + b)     # 보여주기만 함

x = add(2, 3) # 화면엔 5가 찍히지만 x = None

전역 변수 vs 지역 변수#

함수 안에서 만든 변수는 함수 밖에서 쓸 수 없습니다.

x = "전역"          # 어디서든 접근 가능

def my_func():
    y = "지역"      # 이 함수 안에서만 존재
    print(x)        # 전역변수 읽기 OK

my_func()
print(y)            # NameError! — 함수 밖에는 y가 없음

함수 vs 메서드 — 무엇이 다른가#

둘 다 기능 묶음이지만 부르는 방법이 다릅니다.

구분 함수 (Function) 메서드 (Method)
호출 함수명(자료) 자료.메서드명()
특징 범용 기능 특정 자료형에 딸린 기능
예시 len(my_list) my_list.append(4)

📌 보충 — 실무에서 함수를 쓰는 법 (타입 힌트 & 독스트링)#

수업 마지막에 다룬, 함수를 전문가답게 쓰는 두 가지 관행입니다. 코드의 가독성과 협업 효율을 크게 높입니다.

타입 힌트 (Type Hint)#

매개변수와 반환값의 자료형을 명시해 둡니다. 강제는 아니지만, 코드를 읽는 사람과 에디터가 실수를 빨리 잡게 도와줍니다.

# 타입 힌트 없음 — a, b가 뭔지 알 수 없음
def add(a, b):
    return a + b

# 타입 힌트 있음 — int 두 개를 받아 int를 반환한다고 명확히 표현
def add(a: int, b: int) -> int:
    return a + b

독스트링 (Docstring)#

함수 첫 줄에 """설명"""을 적으면 그 함수의 설명서가 됩니다. help(함수명)으로 볼 수 있고, 오픈소스 라이브러리 공식 문서도 대부분 여기서 자동 생성됩니다.

def celsius_to_fahrenheit(celsius: float) -> float:
    """섭씨 온도를 화씨 온도로 변환합니다.

    Args:
        celsius (float): 변환할 섭씨 온도
    Returns:
        float: 변환된 화씨 온도
    """
    return celsius * 9 / 5 + 32

help(celsius_to_fahrenheit)   # 위 설명이 그대로 출력됨

마무리#

오늘 배운 것을 한 문장으로 묶으면 이렇습니다. “데이터를 묶고(튜플·딕셔너리), 반복으로 처리하고(for·while), 그 처리를 함수로 포장해 재사용한다.”

이 세 가지가 합쳐지면 “성적표를 분석하고”, “재고를 계산하고”, “로그인을 처리하는” 실제 프로그램이 됩니다. 머리로만 읽지 말고 직접 손으로 쳐보면서 익히세요. 💪
