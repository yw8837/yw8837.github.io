처음 리눅스 터미널(검은 화면)을 마주하면 마우스도 안 먹히고 막막하게 느껴질 수 있습니다. 하지만 걱정하지 마세요! 리눅스 명령어는 우리가 평소 윈도우에서 ‘마우스로 클릭해서 하던 행동’을 ‘키보드로 타자를 쳐서’ 하는 것일 뿐입니다.

오늘은 코딩을 1도 모르는 비전공자도 무작정 따라 하며 익힐 수 있는 가장 기초적인 리눅스 명령어들을 정리해 보았습니다.

1. 지금 여기는 어디? (현재 위치 확인 및 이동)#

탐색기를 열었을 때 지금 내가 어느 폴더에 들어와 있는지 확인하고, 다른 폴더로 이동하는 방법입니다.

📍 pwd : 내 현재 위치 확인하기#

마우스로 폴더 창 위의 경로를 확인하는 것과 같습니다. 내가 있는 곳의 절대 경로(전체 주소)를 보여줍니다.

$ pwd
/c/Users/최용우/Desktop/TEST

🏃‍♂️ cd : 다른 폴더로 이동하기 (Change Directory)#

원하는 방(폴더)으로 들어가는 명령어입니다.

💡 꿀팁: ~ (물결표)는 내 컴퓨터의 기본 시작 방(홈 디렉터리)을 뜻합니다.

# 바탕화면으로 바로 이동하기
$ cd ~/Desktop

👀 ls : 현재 폴더 내용물 보기 (List)#

현재 방 안에 어떤 파일과 폴더가 있는지 목록을 쫙 보여줍니다.

# 기본 목록 보기
$ ls

# 숨김 파일까지 포함해서 만든 날짜, 용량 등 상세 정보까지 보기
$ ls -al

2. 폴더(디렉터리) 만들기 및 이동#

우클릭 후 ‘새 폴더’를 만드는 작업을 터미널에서는 이렇게 합니다.

📁 mkdir : 새 폴더 만들기 (Make Directory)#

# TEST 폴더 안에서 'linux_practice' 라는 폴더 만들기
$ mkdir linux_practice

💡 응용하기 (-p 옵션): 폴더 안에 폴더를 한 번에 여러 개 중첩해서 만들고 싶을 때는 -p를 붙여주세요.

$ mkdir -p linux_practice/src/utils

🧭 만든 폴더와 상위 폴더로 이동하기#

# 방금 만든 폴더로 이동하기
$ cd linux_practice

# 상위 폴더(뒤로 가기)로 이동하기
$ cd ..

(.. 은 윈도우 탐색기에서 ‘뒤로 가기’ 버튼을 누른 것과 똑같은 역할입니다.)

3. 파일 만들기 및 내용 확인#

메모장을 열고 글을 쓴 뒤 저장하는 과정입니다.

📄 touch : 빈 파일 만들기#

마우스 우클릭 후 ‘새 텍스트 문서’를 만드는 것과 같습니다. 연습용 폴더로 이동한 뒤 빈 파일을 생성해 봅니다.

$cd ~/Desktop/TEST/linux_practice$ touch hello.txt

✏️ 파일에 글씨 쓰기 (echo)#

메모장을 직접 열지 않고도 밖에서 바로 글씨를 밀어 넣을 수 있습니다.

# hello.txt 파일에 "hello, linux!" 라는 글자 넣기 (덮어쓰기)
$ echo "hello, linux!" > hello.txt

# 그 밑에 두 번째 줄 추가하기 (내용 덧붙이기)
$ echo "두 번째 줄 추가" >> hello.txt

⚠️ 주의하세요! > 기호는 기존 내용을 싹 지우고 덮어쓰기를 합니다. 실수로 기존 데이터를 날릴 수 있으니, 가급적이면 내용을 안전하게 이어 붙이는 >> 기호를 사용하는 것을 추천합니다.

📖 cat : 파일 내용 확인하기#

파일을 더블클릭해서 열어보듯, 터미널 화면에 파일의 전체 내용을 시원하게 출력해 줍니다.

$ cat hello.txt

🛠️ 개발자의 필수 도구, vi 편집기 익히기#

마우스 없이 키보드만으로 글을 수정할 수 있는 리눅스의 기본 메모장입니다. 기획자나 교양으로 가볍게 공부하시는 분들은 패스하셔도 좋지만, 개발자를 지망하신다면 앞으로 마크다운(MD) 작업을 할 때 익혀두시는 것을 강력 추천합니다!

처음엔 빠져나오는 법을 몰라 당황하기 쉬우니 아래 필수 단축키 6가지만 기억하세요.

키 동작 설명
i 삽입 모드 진입 (Insert: 현재 커서 위치부터 글을 쓸 수 있음)
ESC 일반 모드로 복귀 (글쓰기를 멈추고 명령을 내릴 준비)
:w 저장 (Write)
:q 종료 (Quit)
:wq 저장하고 종료 (가장 많이 쓰이는 콤보!)
:q! 저장 안 하고 강제 종료 (작성하다가 실수했을 때 유용해요)

4. 파일 폴더 복사, 이동, 삭제#

👯‍♂️ cp : 복사해서 붙여넣기 (Copy)#

cp [원본] [복사본] 순서로 이름과 경로를 지정합니다.

# hello.txt를 복사해서 hello_backup.txt 만들기
$ cp hello.txt hello_backup.txt
  • 폴더 전체를 통째로 복사하려면 반드시 뒤에 -r 옵션을 붙여야 합니다.
$ cp -r linux_practice/ linux_practice_backup

🚚 mv : 파일 폴더 이동 / 이름 변경 (Move)#

잘라내기 후 다른 곳에 붙여넣는 명령어입니다. 같은 위치에서 사용하면 파일 이름을 바꾸는 용도로 쓰입니다.

# 1. 이름 바꾸기 (hello_backup.txt의 이름을 hello_copy.txt로 변경)
$ mv hello_backup.txt hello_copy.txt

# 2. 폴더를 새로 만들고 거기로 파일 이동하기
$ mkdir archive
$ mv hello_copy.txt archive

🗑️ rm : 파일 삭제하기 (Remove)#

리눅스 터미널에서 지운 파일은 휴지통을 거치지 않고 영구 삭제되니 매우 신중하게 사용해야 합니다.

# 방금 archive 폴더로 이동한 파일 삭제하기
$ rm archive/hello_copy.txt
  • 폴더를 통째로 지울 때는 복사할 때처럼 -r 옵션을 함께 씁니다.
$ rm -r archive

🚨 절대 주의 명령어: rm -rf -r(폴더째로)과 -f(묻지도 따지지도 않고 강제로)가 합쳐진 무시무시한 명령어입니다. 이 명령어 뒤에 중요한 폴더 경로를 실수로 잘못 적으면 컴퓨터 시스템이 복구 불가능하게 통째로 날아갈 수도 있으니, 초보자분들은 항상 확인하고 또 확인한 뒤에 사용해야 합니다.

$ rm -rf 폴더나파일이름

5. 🎁 왕초보를 위한 터미널 생존 꿀팁 4가지 (필독!)#

명령어를 일일이 다 치려니 오타도 나고 답답하셨죠? 이 4가지만 알면 리눅스 고수처럼 터미널을 다룰 수 있습니다.

  1. Tab 키 (자동 완성 마법) 🪄 파일이나 폴더 이름의 앞 1~2글자만 치고 Tab 키를 눌러보세요. 리눅스가 찰떡같이 알아듣고 나머지 이름을 자동으로 완성해 줍니다. 이름이 길 때 오타를 방지해 주는 최고의 단축키입니다.

  2. ↑ ↓ 위/아래 방향키 (과거 기억하기) ⏪ 방금 쳤던 명령어를 다시 치고 싶을 때 쓰세요. 키보드의 위(↑) 화살표를 누르면 이전에 입력했던 명령어들이 하나씩 튀어나옵니다. 오타가 났을 때 처음부터 다시 치지 말고, 위 화살표를 눌러 불러온 뒤 틀린 곳만 수정하세요!

  3. history (내가 걸어온 길 돌아보기) 📜 “아까 내가 뭐라고 쳤더라?” 싶을 때는 터미널에 history라고 쳐보세요. 지금까지 입력했던 명령어들의 족보가 번호와 함께 쫙 나옵니다.

  4. Ctrl + L (1초 만에 화면 청소하기) 🧹 이것저것 연습하다 보면 화면이 꽉 차서 어지러울 때가 있죠. clear 라고 타이핑해도 되지만, 진정한 고수는 단축키를 씁니다. 키보드에서 Ctrl 과 L 을 동시에 눌러보세요. 지저분한 터미널 화면이 0.1초 만에 새것처럼 깨끗해집니다!

마무리하며

검은 화면에 흰 글씨만 있어서 처음엔 외계어 같지만, 자주 쓰는 명령어 몇 개와 오늘 알려드린 Tab 키, Ctrl + L 단축키 꿀팁만 손에 익으면 마우스로 클릭하는 것보다 훨씬 빠르고 편해집니다. 오늘 배운 내용들을 바탕으로 내 컴퓨터에서 차근차근 연습해 보세요!
