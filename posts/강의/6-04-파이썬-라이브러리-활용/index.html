이어드림스쿨 AI 과정 파이썬 라이브러리 활용 정리입니다. 남이 만든 강력한 도구를 가져다 쓰고, 내 코드를 전 세계에 공유하는 법까지 배웁니다. 📦🌍

📖 수업 내용#

01 · 라이브러리 세계 탐험하기#

라이브러리(Library) = 누군가 미리 만들어 둔 코드 묶음. 바퀴를 다시 발명하지 않고 가져다 쓰는 게 핵심이에요.

구분 설명 예시
표준 라이브러리 파이썬에 기본 내장 (설치 불필요) math, random, datetime, os, json
외부 라이브러리 따로 설치해서 사용 numpy, pandas, requests, matplotlib

대표적인 외부 라이브러리:

  • numpy — 수치·배열 계산 / pandas — 표 데이터 분석
  • matplotlib·seaborn — 그래프 시각화 / requests — 웹 요청
  • scikit-learn — 머신러닝 / BeautifulSoup — 크롤링

💡 전 세계 개발자가 만든 라이브러리는 PyPI (Python Package Index)라는 거대한 창고에 모여 있어요. 여기서 pip로 내려받습니다.

02 · 라이브러리 설치하기 — pip#

pip = 파이썬 패키지 설치 도구. 터미널에서 사용합니다.

pip install pandas            # 설치
pip install pandas==2.2.0     # 특정 버전 설치
pip install --upgrade pandas  # 업그레이드
pip uninstall pandas          # 삭제
pip list                      # 설치된 목록 보기

가상환경 + requirements.txt (팀 협업의 기본):

pip freeze > requirements.txt    # 현재 설치 목록을 파일로 저장
pip install -r requirements.txt  # 그 목록대로 한 번에 설치

💡 우리 과정은 uv로 패키지를 관리하죠 — uv add pandas, uv sync. → 개발 환경 설정(uv) 💡 가상환경을 쓰면 프로젝트마다 라이브러리 버전이 안 섞입니다.

03 · 라이브러리 사용하기 — import#

설치한 라이브러리는 import로 불러옵니다.

import pandas as pd            # 관례적 별칭(as)
import numpy as np
import matplotlib.pyplot as plt

# pandas로 표 데이터 다루기
df = pd.DataFrame({"이름": ["Alice", "Bob"], "점수": [95, 82]})
print(df["점수"].mean())       # 88.5

# numpy로 배열 계산
arr = np.array([1, 2, 3, 4])
print(arr.mean())              # 2.5

💡 import 라이브러리 as 별칭은 관례예요 (pandas→pd, numpy→np). 공식 문서·예제도 이 별칭을 씁니다. 💡 사용법이 막히면 공식 문서를 보는 습관이 중요합니다 (라이브러리마다 docs 사이트가 있어요).

04 · 내 코드를 전세계 사람과 공유하기 (PyPI 배포)#

내가 만든 유용한 코드도 패키지로 만들어 PyPI에 올리면 누구나 pip install로 쓸 수 있어요.

큰 흐름:

1. 패키지 구조 만들기 (폴더 + 코드 + pyproject.toml)
2. 빌드(build)로 배포 파일 생성
3. PyPI에 업로드(twine)
4. 누구나 pip install 내패키지

# 1) 빌드 도구·업로드 도구 설치
pip install build twine

# 2) 배포 파일 생성 (dist/ 폴더에 .whl, .tar.gz 생성)
python -m build

# 3) PyPI에 업로드 (PyPI 계정·토큰 필요)
twine upload dist/*

핵심 설정 파일 pyproject.toml (패키지 이름·버전·의존성 정의):

[project]
name = "my-package"
version = "0.1.0"
dependencies = ["requests"]

💡 처음엔 TestPyPI에 먼저 올려 연습하는 걸 권장. 실수해도 안전해요.

📚 참고자료#

수업에 더해 공식 문서로 보충: pip 문서 · PyPI · 패키징 가이드

모듈/패키지 vs 라이브러리#

  • 모듈 = .py 파일 하나 / 패키지 = 모듈 담은 폴더 / 라이브러리 = 패키지(들)을 묶어 배포한 것. → 모듈과 패키지

버전 표기 (시맨틱 버저닝)#

major.minor.patch (예: 2.2.0). 큰 변화=major, 기능 추가=minor, 버그 수정=patch.

pip install이 안 될 때#

  • 가상환경이 활성화됐는지 확인 / 오타·대소문자 / pip 대신 python -m pip 시도.

마무리#

라이브러리는 “남이 만든 도구를 가져다 쓰는 것”, PyPI는 그 도구들의 거대한 창고. pip install 한 줄로 전 세계 개발자의 작업을 빌려 쓰고, 내 코드도 twine upload로 세상에 내놓을 수 있다.

numpy·pandas 같은 도구 덕분에 우리는 복잡한 계산·분석을 몇 줄로 해냅니다. 앞으로 데이터 분석·AI에서 매일 만나게 될 거예요. 🚀
