이어드림스쿨 AI 과정 파이썬 중급 문법2 — 실무 문법 패턴 정리입니다. 기초 문법 위에, 실무에서 코드를 짧고 깔끔하게 쓰는 6가지 패턴을 배웁니다. 🧩

📖 수업 내용#

01 · f-string 포매팅#

문자열 앞에 f를 붙이고 { } 안에 변수·식을 넣습니다. (Python 3.6+)

name, salary = "Alice", 6500
print(f"{name}님 연봉: {salary}만원")     # Alice님 연봉: 6500만원
print(f"{15} + {4} = {15 + 4}")           # 식도 가능 → 15 + 4 = 19

숫자 포맷 (자주 씀):

pi = 3.14159
print(f"{pi:.2f}")        # 3.14      소수점 2자리
print(f"{1234567:,}")     # 1,234,567 천 단위 콤마
print(f"{0.123:.1%}")     # 12.3%     퍼센트
print(f"{'INFO':>7}")     # 오른쪽 정렬 7칸

💡 :.2f(소수자리), :,(콤마), :%(퍼센트), :>7(정렬) — 표·로그 출력에 유용.

02 · 리스트 컴프리헨션 (List Comprehension)#

for 반복문으로 리스트 만드는 걸 한 줄로 압축합니다.

# 기본: [표현식 for 변수 in 시퀀스]
squares = [i**2 for i in range(1, 6)]        # [1, 4, 9, 16, 25]

# 필터: [표현식 for 변수 in 시퀀스 if 조건]
evens = [i for i in range(10) if i % 2 == 0] # [0, 2, 4, 6, 8]

# if-else (순서 주의!): [A if 조건 else B for 변수 in 시퀀스]
grades = ["합격" if s >= 60 else "불합격" for s in [80, 50, 90]]

실무 예 — 데이터 전처리:

raw = [' Python ', 'SQL', ' ', 'Docker ', '']
clean = [s.strip() for s in raw if s.strip()]   # ['Python', 'SQL', 'Docker']

⚠️ 필터 if는 뒤에(for ... if 조건), if-else는 앞에(A if 조건 else B for ...). 위치가 다릅니다!

03 · sorted — 정렬#

scores = [85, 92, 78, 96]
sorted(scores)                 # [78, 85, 92, 96]  원본 유지, 새 리스트
sorted(scores, reverse=True)   # [96, 92, 85, 78]  내림차순
원본 반환
list.sort() 변경됨 None
sorted(list) 유지 정렬된 새 리스트

key로 정렬 기준 지정 (실무 핵심):

members = [{"name":"A","salary":6500}, {"name":"B","salary":4800}]
sorted(members, key=lambda m: m["salary"], reverse=True)   # 연봉 높은 순
sorted(words, key=len)                                     # 글자 수 순
sorted(members, key=lambda m: (m["team"], -m["salary"]))   # 다중 기준

💡 key=lambda ... → “무엇을 기준으로 정렬할지"를 함수로 지정. 튜플 (기준1, 기준2)로 다중 정렬.

04 · enumerate — 인덱스 + 값 동시에#

for i, season in enumerate(["봄", "여름", "가을"]):
    print(i, season)          # 0 봄 / 1 여름 / 2 가을

for rank, team in enumerate(["개발팀", "기획팀"], start=1):
    print(f"{rank}번: {team}")  # 1번: 개발팀 / 2번: 기획팀

💡 range(len(...)) 대신 enumerate가 훨씬 깔끔. start=1로 1번부터 셀 수 있어요(순위 매기기).

05 · lambda · map · filter#

lambda = 이름 없는 한 줄 함수.

square = lambda x: x ** 2     # def square(x): return x**2 와 동일
square(5)                     # 25

map = 각 요소에 함수 적용 / filter = 조건 맞는 것만:

nums = [1, 2, 3, 4, 5]
list(map(lambda x: x*2, nums))        # [2, 4, 6, 8, 10]
list(filter(lambda x: x%2==0, nums))  # [2, 4]   (짝수만)

💡 map/filter 결과는 list()로 감싸야 보입니다. 복잡한 로직은 lambda 말고 일반 def 함수가 가독성↑.

06 · if __name__ == "__main__":#

파이썬 파일을 직접 실행할 때만 동작하는 블록. import로 불러오면 실행 안 됨.

def add(a, b):
    return a + b

if __name__ == "__main__":     # 이 파일을 직접 실행할 때만
    print(add(3, 4))           # import 시엔 실행 안 됨

💡 “함수·클래스 정의"와 “직접 실행 코드"를 분리하는 장치. 모듈로 재사용하면서 테스트 코드도 넣을 수 있어요.

📚 참고자료#

수업에 더해 Python 공식 문서에서 보충.

딕셔너리 컴프리헨션#

리스트뿐 아니라 딕셔너리도 한 줄로:

members = [{"name":"A","salary":6500}, {"name":"B","salary":5200}]
{m["name"]: m["salary"] for m in members}   # {'A': 6500, 'B': 5200}

map vs 컴프리헨션#

같은 일을 둘 다 할 수 있어요. 보통 컴프리헨션이 더 읽기 쉬워 선호됩니다.

list(map(lambda x: x*2, nums))   # map
[x*2 for x in nums]              # 컴프리헨션 (권장)

sys.exit()#

프로그램 종료 함수. sys.exit(0)=정상, 그 외=오류. (주피터에선 커널이 죽으니 .py에서만)

마무리#

f-string으로 깔끔하게 출력하고, 컴프리헨션으로 반복을 한 줄로 줄이고, sorted·enumerate·lambda로 데이터를 자유롭게 다룬다. 이 패턴들은 “되는 코드"를 “읽기 좋고 짧은 코드"로 바꿔줍니다 — 실무에서 매일 씁니다.

처음엔 한 줄 압축이 어색하지만, for문으로 풀어 써본 뒤 컴프리헨션으로 바꿔보면 금방 익숙해져요. 💪
