이어드림스쿨 AI 과정 파이썬 중급 — 모듈과 패키지 정리입니다. 남이 만든 코드와 내가 만든 코드를 가져다 쓰는 법을, 처음 배우는 분도 이해하게 풀어 썼습니다. 📦

📖 수업 내용#

01 · 모듈(Module)이란?#

모듈 = 파이썬 코드(함수·변수 등)가 담긴 .py 파일 하나. 잘 만들어진 코드를 매번 새로 짜지 않고 가져다 쓰기 위해 씁니다. 가져올 때는 import.

import random              # random 모듈을 통째로 가져오기

print(random.randrange(1, 7))   # 1~6 중 무작위 (주사위)

💡 모듈이름.함수() 형태로 씁니다 — “random 모듈 안의 randrange 함수”.

02 · 표준 라이브러리 — 파이썬이 기본 제공#

설치 없이 바로 import해서 쓰는 모듈 모음입니다. 대표 두 가지:

import math
print(math.pi)        # 3.141592...
print(math.sqrt(16))  # 4.0  (제곱근)

import random
print(random.randrange(1, 7))   # 주사위
print(random.choice(["가위", "바위", "보"]))   # 무작위 선택

📚 어떤 표준 모듈이 있는지는 공식 목록에서 볼 수 있어요. (math, random, datetime, os, json …)

03 · import 4가지 방법#

# ① 통째로 가져오기 — 모듈명.함수()
import math
math.sqrt(9)

# ② 별칭(as) — 긴 이름을 짧게
import random as rd
rd.randrange(1, 7)

# ③ 특정 것만 콕 집어 (from ~ import) — 모듈명 없이 바로
from math import sqrt, pi
print(sqrt(9), pi)

# ④ 전부 가져오기 (* — 비권장)
from math import *

💡 from math import *(④)는 어떤 이름이 들어오는지 헷갈려서 실무에선 잘 안 씁니다. ②·③을 권장.

04 · 내가 만든 모듈 — 직접 .py 만들어 가져오기#

내가 만든 .py 파일도 모듈이 됩니다. 예를 들어 cal.py를 만들고:

# cal.py
def plus(a, b):
    c = a + b
    return c

같은 폴더의 다른 파일(main.py)에서 가져다 씁니다:

# main.py
import cal                       # cal.py 가져오기
print(cal.plus(3, 4))            # 7

# 또는 함수만 콕 집어
from cal import plus
print(plus(3, 4))                # 7

💡 import cal 에서 .py는 빼고 파일 이름만 씁니다.

05 · 패키지(Package) — 모듈을 폴더로 묶기#

모듈(.py)이 많아지면 폴더로 분류합니다. 이렇게 모듈을 담은 폴더가 패키지예요.

project/
├── script/
│   └── main.py
└── sound/
    ├── audio.py
    └── play.py

폴더 구조를 점(.) 으로 따라 들어가 가져옵니다:

import sound.audio              # sound 폴더의 audio 모듈
from sound.play import start    # sound/play.py 의 start 함수

💡 정리하면 — 모듈 = 파일(.py), 패키지 = 모듈을 담은 폴더. 점(.)으로 경로를 따라갑니다.

📚 참고자료#

수업에 더해 알아두면 좋은 내용을 Python 공식 문서에서 보충했습니다.

if __name__ == "__main__":#

모듈을 직접 실행할 때만 동작하고, import될 때는 실행 안 되게 하는 장치. 모듈에 테스트 코드를 넣을 때 자주 씁니다.

# cal.py
def plus(a, b): return a + b

if __name__ == "__main__":   # cal.py를 직접 실행할 때만
    print(plus(2, 3))        # import되면 이 줄은 안 돌아감

표준 모듈 ≠ 외부 패키지 (pip)#

  • 표준 라이브러리: 설치 없이 바로 import (math, random …)
  • 외부 패키지: pip install로 설치 후 사용 (numpy, pandas, requests …)
  • 우리 과정은 uv로 패키지를 관리하죠 → 개발 환경 설정(uv)

__init__.py 와 모듈 검색 경로#

  • 예전엔 패키지 폴더에 __init__.py(빈 파일)를 둬야 패키지로 인식됐어요. (지금은 없어도 인식되지만 관례로 둠)
  • 파이썬은 정해진 검색 경로에서 모듈을 찾습니다 (import sys; print(sys.path)로 확인).

마무리#

모듈은 코드가 든 파일(.py), 패키지는 그 파일들을 담은 폴더. 잘 만든 코드를 import 한 줄로 가져다 쓰는 것 — 바퀴를 다시 발명하지 않는 게 프로그래밍의 핵심입니다.

import random 한 줄로 주사위를 굴릴 수 있다는 건, 전 세계 개발자가 만든 도구를 공짜로 쓰는 것과 같아요. 앞으로 numpy·pandas 같은 강력한 패키지도 이렇게 불러옵니다. 🚀
