6/22 확률과 통계적 추론 — scipy·statsmodels 가설검정·빅분기 작업형3유형 코드 노트

6/22 강의 — 확률과 통계적 추론 — 의 실습편. 강사 배포 노트북(통계분석_실습_강의용.ipynb, 작업형_제3유형 610회, titanic_pandas_answers.ipynb)의 원본 코드를 그대로 수록하고 각 블록에 목적·해석 주석을 단다. scipy/statsmodels로 독립 t검정(Levene 등분산→ttest_ind), 대응 t검정(ttest_rel), ANOVA+Tukey HSD, 카이제곱 독립성(chi2_contingency), 다중회귀(smf.ols), 로지스틱(smf.logit)을 취업/HR/마케팅 종합문제로 구현하고, 빅분기 기출 610회(Anderson 정규성·Wilcoxon 비모수·로지스틱 오즈비/잔차이탈도/오분류율·다중회귀 RMSE/MSE)와 titanic pandas 10문제(loc 필터·groupby·결측치·문자열·lambda·numpy 벡터화)로 마무리한다. 작업형 DATA_PATH는 Udemy→이어드림 드라이브 경로 교체 안내. 원본과 코드가 상충하는 지점(7회 잔차이탈도, 9회 반올림 자릿수)은 원문 확인 태그로 보존.

6/22 확률과 통계적 추론 — 동전 던지기부터 가설검정·빅분기 작업형3유형까지

4주차 넷째 날. 어제까지 자료를 요약·시각화했다면, 오늘은 “표본으로 모집단을 추론하는” 통계학의 뼈대를 세운다. 확률 기초(표본공간·사건·순열/조합·조건부확률·독립)에서 출발해 확률변수와 확률분포(이산 베르누이·이항·초기하·포아송, 연속 균일·정규·표준정규, PMF/PDF/CDF)를 다지고, 통계적 추론(모집단/표본, 점추정·구간추정·신뢰구간)과 가설검정 이론(귀무/대립가설, 1종·2종 오류, 유의수준 α, 기각역·p-value, 이항검정·z검정)까지 이어진다. 후반은 빅데이터분석기사 실기 작업형 제3유형 — scipy/statsmodels로 t검정(단일/독립/대응)·정규성(Shapiro/Anderson)·등분산(Levene)·비모수(Wilcoxon)·카이제곱(적합도/독립성)·ANOVA+Tukey·상관·다중회귀·로지스틱을 코드로 구현한다. “어떤 상황에 어떤 검정을 고르나"를 표로 정리하고, 취업/HR/마케팅 종합문제와 기출 6~10회, titanic pandas 실습으로 손에 익힌다.
