6/29 머신러닝 기초 — 로지스틱 회귀로 타이타닉 생존 예측

AI실무기본 1주차 셋째 날. titanic 데이터로 “생존/사망(0·1)“을 예측하는 이진 분류를 로지스틱 회귀로 처음부터 끝까지 손으로 돌려본다. 왜 선형회귀가 아니라 로지스틱인가(선을 확률로 눌러 담는 시그모이드), 계수를 어떻게 읽나(부호·p-value·오즈비 exp(β)), 모델을 어떻게 평가하나(정확도만으론 왜 부족한가 → 혼동행렬·정밀도·재현율·F1), 특성 중요도를 계수 절댓값으로 보는 법까지. sklearn 편의함수 대신 NumPy로 분할·지표를 직접 계산해 원리를 드러내는 게 이 수업의 핵심. ⚠ 노션 라이브본이 유일 소스라 데이터 로드·전처리·모델 적합·예측 코드는 원문에 없어 복원 보강했고(코드 노트에서 [보강] 표기), 이론 정의는 표준 개념 보강임을 명시한다.
