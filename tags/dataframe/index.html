pandas 예제 70선(pandas_예제.ipynb)과 vectorization.ipynb를 강사 원본 코드+출력 그대로 따라가며, 6/18 강의 1부 — 데이터 로드·점검(shape/info/describe), loc/iloc, 조건 필터링(Boolean·&·|·isin·컬럼 간 비교), 정렬, groupby/agg/unstack — 을 군 데이터셋(서버·군수품·복지 각 11,000행)으로 직접 돌려본다. 실행 환경설정(코랩 한글폰트·drive.mount·경로/파일명 FileNotFoundError·NFC/NFD 자모분리)을 디버깅 포인트로 먼저 짚고, 원본 예제의 두 가지 함정 — 문제27(60~80 구간이 Empty DataFrame), 문제61(inner merge가 0행) — 을 실제 출력과 함께 왜 그런지 정정·설명한다. 후반부 자료 제공분(결측/문자열/시계열/merge)과 벡터화(루프 17.3ms vs 벡터 0.4ms, 39.4배)까지 수록.

6/18 pandas & 데이터 시각화 — 표를 가공하는 손과, 데이터를 보여주는 눈

4주차 둘째 날. 어제 NumPy(분석의 손)를 잡았다면 오늘은 그 위에 선 pandas로 실제 표 데이터를 가공하고, 후반부엔 그 결과를 어떻게 보여줄지 — 데이터 시각화 이론을 다룬다. 1부 pandas는 군 데이터셋(서버·군수품·복지 각 11,000행)으로 데이터 로드·점검(shape/info/describe) → DataFrame vs Series → loc/iloc → 조건 필터링(단일·복합·isin·컬럼 간 비교) → 정렬 → groupby/agg/unstack 집계까지 70제 실습. 핵심은 Split-Apply-Combine과 벡터화. 2부 데이터 시각화는 나이팅게일 Rose Diagram과 앤스컴 콰르텟으로 “왜 시각화인가"를 짚고, 시각화 원리(삭제>분리>강조>배열), 미학 요소·좌표계·색상 스케일(CVD-safe), 목적별 차트, 비례 잉크 원칙까지 이론으로 다룬 뒤 matplotlib/seaborn/plotly/streamlit 실습을 후속 차시로 예고했다.
