6/19 통계 자료의 요약 & 시각화 — seaborn tips 통계요약·실습 코드 노트

matplotlib 시각화 원칙.ipynb와 viz_basic_01.ipynb(코드 16셀)를 강사 원본 코드 그대로 따라가며, 6/19 강의 — 통계 자료의 요약(논리적·시각화) — 을 seaborn tips(244건)로 직접 돌려본다. 자료형 분류(cell 6) → 도수분포표·교차표(cell 8) → 원형·막대(cell 10) → Sturges 도수분포표(cell 12) → 히스토그램·도수다각형(cell 14/16) → 산점도(cell 18) → 중심위치 mean 19.79·median 17.80·mode 13.42(cell 21) → 산포 std 8.90·IQR 10.78·CV 45%(cell 23) → 백분위수(cell 25) → 상자그림(cell 27) → 도수분포표 요약 midpoint(cell 29) → 분할표(cell 31) → 공분산·상관 r=0.6757(cell 33). matplotlib fig/ax 객체지향(원칙 노트북)과 Okabe-Ito 색 셋업도 수록. 환경 디버깅 — Colab 한글폰트 설치+런타임 재시작, Categorical 컬럼 fillna 에러 → astype(object) 해결. 점도표·줄기잎그림은 노트북에 코드 없음(이론만). 치우친 분포 평균–중앙값은 봉우리/꼬리 두 관례로 분리.
