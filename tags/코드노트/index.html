5/29 파이썬 실습 코드 노트

수업 실습 코드를 섹션별로 정리하고, 수업에서 다루지 못한 파이썬 공식 문서의 유용한 내용도 함께 담았습니다. 코드를 그냥 읽지 말고 직접 Colab에서 하나씩 쳐보세요! 🚀 섹션 1 : 기초 자료형과 변수 print() 기본 사용법 print("Hello, Python!") # Hello, Python! print("안녕", "파이썬", "!") # 안녕 파이썬 ! (콤마로 구분하면 띄어쓰기 자동 추가) print("안녕" + "파이썬") # 안녕파이썬 (+ 는 붙여서 출력) 자료형 5가지 # 정수 (int) num_int = 42 print(type(num_int)) # <class 'int'> # 실수 (float) num_float = 3.14 print(type(num_float)) # <class 'float'> # 문자열 (str) text = "파이썬" print(type(text)) # <class 'str'> # 리스트 (list) my_list = [1, 2, 3] print(type(my_list)) # <class 'list'> # 불리언 (bool) flag = True print(type(flag)) # <class 'bool'> 변수와 연산자 # 기본 사칙연산 a, b = 10, 3 print(a + b) # 13 print(a - b) # 7 print(a * b) # 30 print(a / b) # 3.3333333333333335 # 특수 연산자 print(a // b) # 3 (몫: 소수점 버림) print(a % b) # 1 (나머지) print(a ** b) # 1000 (10의 3승) 문자열 연산 (+, *) first_name = "길동" last_name = "홍" # 문자열 더하기 (이어 붙이기) full_name = last_name + first_name print(full_name) # 홍길동 # 문자열 곱하기 (반복) print("파이썬! " * 3) # 파이썬! 파이썬! 파이썬! # 숫자를 문자열로 변환해서 합치기 age = 25 print("나는 " + str(age) + "살 입니다.") # 나는 25살 입니다. print(f"나는 {age}살 입니다.") # 나는 25살 입니다. (f-string 방식) 인덱싱과 슬라이싱 word = "Python" # 0 1 2 3 4 5 # -6-5-4-3-2-1 # 인덱싱 print(word[0]) # P print(word[-1]) # n (마지막 글자) print(word[2]) # t # 슬라이싱 [시작:끝] ← 끝 번호는 포함 안 됨 beta = "abcdefg" print(beta[2:5]) # cde (인덱스 2, 3, 4) print(beta[:3]) # abc (처음 ~ 인덱스 2) print(beta[4:]) # efg (인덱스 4 ~ 끝) print(beta[:]) # abcdefg (전체) 중첩 리스트 접근 student_info = ["홍길동", 20, "컴퓨터공학", ["파이썬", "자바", "C++"]] print(student_info[0]) # 홍길동 print(student_info[3]) # ['파이썬', '자바', 'C++'] print(student_info[3][0]) # 파이썬 (리스트 안의 리스트 → [행][열] 로 접근) print(student_info[3][2]) # C++ 섹션 2 : 조건문 input() — 주의사항 # input() 의 반환값은 항상 str(문자열)! num1 = input("숫자 입력: ") # "100" 입력 num2 = input("숫자 입력: ") # "300" 입력 print(num1 + num2) # 100300 ← 문자열 이어붙이기가 됨! # 정수로 변환 후 계산 print(int(num1) + int(num2)) # 400 ← 이게 우리가 원하는 결과 형 변환 (Type Casting) # 문자열 → 정수 print(int("42")) # 42 print(int("3.14")) # ValueError! 소수점 있는 문자열은 int() 직접 불가 print(int(float("3.14"))) # 3 ← float 먼저, 그 다음 int # 정수 → 실수 print(float(7)) # 7.0 # 숫자 → 문자열 print(str(100)) # "100" print(str(True)) # "True" # 문자열 → 리스트 print(list("abc")) # ['a', 'b', 'c'] print(list("파이썬")) # ['파', '이', '썬'] if - elif - else 성적 판별 score = int(input("점수를 입력하세요: ")) if score >= 90: grade = "A" elif score >= 80: grade = "B" elif score >= 70: grade = "C" elif score >= 60: grade = "D" else: grade = "F" print(f"당신의 학점은 {grade}입니다.") 실용 예제 모음 BMI 계산기 ...
