6/19 통계 자료의 요약 & 시각화 — 데이터를 수치 하나, 그림 한 장으로 줄이는 법

4주차 셋째 날. 어제 pandas로 표를 깎는 손을 잡았다면, 오늘은 그 표를 “수치 하나·그림 한 장"으로 줄이는 기술통계(자료의 요약)를 배운다. 두 축이다 — (1) 논리적(수치) 요약: 자료의 형태 분류, 도수·도수분포표·교차표, 중심위치(평균·중앙값·최빈값), 산포(분산·표준편차·범위·IQR·변동계수), 백분위수·상자그림, 두 변수 요약(공분산·상관계수, 상관≠인과). (2) 시각화 요약: 점도표·히스토그램·도수다각형·줄기잎그림과 matplotlib fig/ax 객체지향 방식·Wilke/Okabe-Ito 색 원칙. 실습은 seaborn tips(244건)로 전 과정을 코드로 구현한다(total_bill 평균 19.79·표준편차 8.90·IQR 10.78, total_bill–tip 상관 r=0.68). 치우친 분포의 평균–중앙값 관계는 봉우리 기준 vs 꼬리 기준 두 관례가 충돌하므로 둘을 분리해 설명한다.

6/18 pandas & 데이터 시각화 — 표를 가공하는 손과, 데이터를 보여주는 눈

4주차 둘째 날. 어제 NumPy(분석의 손)를 잡았다면 오늘은 그 위에 선 pandas로 실제 표 데이터를 가공하고, 후반부엔 그 결과를 어떻게 보여줄지 — 데이터 시각화 이론을 다룬다. 1부 pandas는 군 데이터셋(서버·군수품·복지 각 11,000행)으로 데이터 로드·점검(shape/info/describe) → DataFrame vs Series → loc/iloc → 조건 필터링(단일·복합·isin·컬럼 간 비교) → 정렬 → groupby/agg/unstack 집계까지 70제 실습. 핵심은 Split-Apply-Combine과 벡터화. 2부 데이터 시각화는 나이팅게일 Rose Diagram과 앤스컴 콰르텟으로 “왜 시각화인가"를 짚고, 시각화 원리(삭제>분리>강조>배열), 미학 요소·좌표계·색상 스케일(CVD-safe), 목적별 차트, 비례 잉크 원칙까지 이론으로 다룬 뒤 matplotlib/seaborn/plotly/streamlit 실습을 후속 차시로 예고했다.

6/17 데이터 리터러시 & NumPy 기초 — 데이터를 읽는 눈과, 분석 패키지의 뼈대

4주차 첫 수업. 공통 기초(파이썬·SQL)에서 데이터 분석 본격 커리큘럼으로 넘어가는 회차다. 전반부는 데이터 리터러시 — 데이터의 정의와 정형/비정형/반정형, 변수의 척도(명목·서열·등간·비율)에 따라 통계 분석법이 갈린다는 점, 양질의 데이터가 분석 신뢰도·ML 성능을 좌우한다는 것(고품질은 희소·고비용), 신뢰할 수 있는 데이터(편향·오류·결측치)와 결측치 처리 전략(정답 없음, 비교 실험), 상관 vs 인과·DIKW·데이터 마이닝·시각화 리터러시까지. 후반부는 NumPy 기초 — pandas·seaborn·scikit-learn의 뼈대인 NumPy로 ndarray 생성·속성, 인덱싱/슬라이싱과 뷰(view) vs 복사(copy), reshape, 불리언(마스킹) 인덱싱, 축(axis) 집계, 그리고 강사가 “가장 중요"라 강조한 브로드캐스팅·벡터화를 다룬다.

6/16 정규화 & 데이터베이스 구현 — 같은 데이터인데 왜 1NF·2NF·3NF로 쪼개야 하는가

지난 시간엔 제약조건·키로 테이블 하나하나를 잘 만드는 법을 배웠다. 오늘은 한 단계 위 — 테이블들을 어떻게 나눠야 데이터가 꼬이지 않는가, 즉 정규화다. 잘못된 설계가 부르는 세 가지 이상현상(삽입·갱신·삭제)에서 출발해, 함수 종속(부분/이행)을 이해하고, 1NF(원자값)→2NF(부분종속 제거)→3NF(이행종속 제거)로 같은 학생·수강 데이터를 단계적으로 쪼갠다. 그 뒤 BCNF·4NF·5NF와 역정규화를 정리하며 “실무는 보통 3NF로 충분"을 짚고, 공유킥보드 최종 4테이블 ERD로 마무리한다. 후반부는 MySQL DB 구현 — 설치, DATABASE 생성, DCL(GRANT/REVOKE), 인덱스. 실습은 SQLite, 구현 슬라이드는 MySQL 기준이라 차이를 라벨로 구분한다.

6/15 데이터베이스 개요 & 구성하기 — DB는 왜 필요하고, 제약조건은 왜 마지막 방어선인가

지금까지는 이미 만들어진 DB에서 SELECT·JOIN·윈도우 함수로 데이터를 꺼내 썼다. 오늘은 방향을 바꿔 DB 자체를 설계하고 만드는 첫 수업이다. DB가 왜 필요한지(파일처리의 한계)부터 시작해 RDB와 NoSQL을 비교하고, CREATE/INSERT/SELECT로 테이블을 만들고, DDL/DML/DCL과 자료형을 정리한 뒤, 핵심인 제약조건(NOT NULL·UNIQUE·DEFAULT·CHECK)과 키(PK·FK·후보·대체·슈퍼키), 무결성, 데이터 모델링과 ERD까지 이어진다. 관통하는 한 문장은 강사님의 “제약조건은 잘못된 데이터를 막는 마지막 방어선"이다.

6/12 그룹 함수 & 윈도우 함수 — 행을 줄이지 않고 통계 컬럼을 옆에 붙이기

어제(6/11) JOIN·서브쿼리를 팠다면, 오늘은 통계·분석 쿼리의 두 축인 윈도우 함수와 그룹 함수를 다뤘다. 실제 수업은 자료 목차 순서가 아니라 이탈고객 분석 → 윈도우 함수(순위·누적합·LAG/LEAD) → 그룹 함수(ROLLUP/CUBE) → classicmodels 실전 순으로 흘렀고, 이 글도 그 라이브 흐름을 그대로 따라간다. 핵심은 윈도우 함수가 GROUP BY와 달리 원본 행을 줄이지 않고 통계 컬럼을 옆에 붙인다는 점, 그리고 SQLite는 ROLLUP/CUBE를 UNION으로 대체한다는 점이다.

6/11 JOIN & 서브쿼리 심화 — 테이블을 가로로 잇고, 쿼리 안에 쿼리를 품기

어제(6/10) 집합 연산자·계층형 질의를 배웠다면, 오늘은 두 테이블을 가로로 잇는 JOIN을 종류별(EQUI/INNER/OUTER/SELF 등)로 정리하고, 쿼리 안에 쿼리를 품는 서브쿼리를 동작 방식(연관/비연관)·반환 형태(단일행/다중행/스칼라)로 분류했다. 마지막엔 VIEW와 Python sqlite3 연동까지. 슬라이드(표준/Oracle)와 실습(SQLite)의 문법 차이가 핵심이다.

6/10 집합 연산자 & 계층형 질의 — 조인 없이 합치고, 조직도처럼 파고들기

어제(6/9) 집계·조인·서브쿼리를 배웠다면, 오늘은 조인 없이 두 결과를 합치는 집합 연산자(UNION·UNION ALL·INTERSECT·EXCEPT)와, 조직도처럼 상하 계층을 파고드는 계층형 질의(재귀 CTE)를 배웠다. 이론은 Oracle/MariaDB 기준, 실습은 SQLite Chinook 기준이라 DBMS 차이가 핵심이다.

6/9 SQL 함수와 서브쿼리 — 집계·GROUP BY·JOIN·서브쿼리로 데이터 깊게 다루기

어제 배운 SELECT 위에 집계함수(COUNT·SUM·AVG·MAX·MIN), 그룹 집계(GROUP BY·HAVING), 여러 테이블 결합(JOIN), 그리고 쿼리 속 쿼리(서브쿼리)를 쌓았다. 핵심 학습법은 “분할 → 각각 실행 → 합치기”.
